# 📝 בנק שאלות תרגול (Practice Question Bank)

- ב) Recon → Scanning → Gaining Access → Maintaining Access → Covering Tracks

**Q2 (פתוחה)** מהם שלושת עקרונות ה-CIA Triad?

**Q3 (בחירה)** בדיקה שבה נותנים לבודק רק שם דומיין, ללא שום מידע נוסף, נקראת:

# ✅ מפתח תשובות (Answer Key)

**Q1** ב. **Q2** Confidentiality, Integrity, Availability. **Q3** ג (Black Box). **Q4** אסור לתקוף אותו (מחוץ ל-Scope = לא מורשה); מותר ומומלץ לתעד ולדווח ללקוח ולהמליץ להוסיפו ל-Scope. **Q5** Vulnerability=הפגם, Exploit=ניצול הפגם, Payload=הקוד שרץ אחרי.

**Q6** ב. **Q7** `>` דורס/יוצר קובץ; `>>` מוסיף בסוף מבלי לדרוס. **Q8** ב (750). **Q9** `sudo -l` — מציג אילו פקודות מותר להריץ כ-root; הרשאות sudo שגויות = מסלול הסלמה קלאסי. (גם `find / -perm -4000` תקין.) **Q10** `/etc/passwd` (רשימת משתמשים, קריא לכולם) ו-`/etc/shadow` (Hash של הסיסמאות, root בלבד).

**Q11** ב. **Q12** 22=SSH, 80=HTTP, 443=HTTPS, 445=SMB, 3389=RDP. **Q13** ג (RST). **Q14** פרטית — טווח 10.0.0.0/8. **Q15** 256 כתובות, 254 שמישות.

**Q16** ב (Staged). **Q17** 0 (אפס). **Q18** `banner.split("/")[1]`. **Q19** ג (Tuple).

**Q20** א (אקטיבי — Sublist3r שולח שאילתות; חלק ממקורותיו פסיביים אך הכלי נחשב לאקטיבי/מעורב). **Q21** לזהות תבנית מייל של הארגון (לפישינג/Spraying בתוך Scope); הכלי: hunter.io. **Q22** `site:target.com filetype:pdf`. **Q23** ב (Proxy).

**Q24** ב (`-p-`). **Q25** מזהה גרסאות שירותים; הגרסה מאפשרת חיפוש Exploit ידוע. **Q26** `enum4linux -a <ip>` ו-`smbclient -L //<ip>/` (או nmap smb-scripts). **Q27** ב (gobuster). **Q28** חקר חולשות; הכלי: `searchsploit` (מאגר Exploit-DB המקומי).

**Q29** ב (Reverse Shell). **Q30** כי חומות אש מתירות לרוב תעבורה **יוצאת**; ב-Reverse הקורבן יוצר חיבור יוצא אל התוקף. **Q31** `RHOSTS` (יעד), `LHOST` (התוקף/Kali), `PAYLOAD` (הקוד שירוץ). **Q32** ב (msfvenom). **Q33** להחליף בין Payload Staged ל-Non-Staged; לייצב Shell (upgrade עם python pty / `stty`).

**Q34** דוגמה: `nmap -sn` (חי?) → `nmap -sC -sV -p-` (פורטים/שירותים) → מנייה לפי שירות (nikto/gobuster/enum4linux) → `searchsploit` (Exploit) → Metasploit/ידני (`set RHOSTS/LHOST/PAYLOAD` → exploit) → `whoami`=root. **Q35** whatweb/nikto → gobuster → זיהוי חולשת Apache 2.4.49 (Path Traversal, CVE-2021-41773) → searchsploit → ניצול. **Q36** כי גילוי יסודי של כל שירות/גרסה/הגדרה קובע אילו Exploits רלוונטיים; דילוג על מנייה = פספוס וקטורי תקיפה והכשלת השלבים הבאים.
