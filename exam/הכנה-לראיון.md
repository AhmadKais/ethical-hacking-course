# 💼 הכנה לראיון עבודה — Junior Pentester / SOC Analyst

> **המטרה:** להכין את הסטודנט ליום הראיון. כאן תמצאו **שאלות טכניות נפוצות עם תשובות-מודל**, **משימות מעשיות** שמעסיק עשוי לבקש בלוח/מסך, ו**שאלות התנהגותיות**. התשובות קצרות ומדויקות — בדיוק איך שעונים בראיון.

> 💡 **כלל הזהב בראיון טכני:** אל תדקלם הגדרה. **ספר סיפור קצר** — "במודול X פרצתי שרת כך: ...". מעסיק רוצה לראות שעשית, לא שקראת.

## חלק א' — שאלות טכניות ותשובות-מודל

### 🔹 יסודות ומתודולוגיה
**ש: מהם שלבי בדיקת חדירה?**
ת: Reconnaissance → Scanning & Enumeration → Exploitation (Gaining Access) → Post-Exploitation & Privilege Escalation → Reporting. (בתוספת Maintaining Access ו-Covering Tracks בתקיפה מלאה.)

**ש: מה ההבדל בין Vulnerability Assessment ל-Penetration Test?**
ת: הערכת חולשות **מזהה ומדרגת** חולשות (רוחב). בדיקת חדירה **מנצלת** אותן כדי להוכיח השפעה אמיתית (עומק). Pentest תמיד כולל ניצול בפועל ו-Scope מוגדר.

**ש: מה ההבדל בין Black / Grey / White Box?**
ת: Black = בלי מידע מוקדם (כמו תוקף חיצוני). White = גישה מלאה לקוד/ארכיטקטורה. Grey = ידע חלקי (למשל משתמש רגיל) — הנפוץ והמשתלם ביותר.

### 🔹 רשתות
**ש: מה ההבדל בין TCP ל-UDP?**
ת: TCP — מבוסס-חיבור, אמין, 3-way handshake (SYN/SYN-ACK/ACK). UDP — ללא חיבור, מהיר, ללא ערובה (DNS, DHCP, VoIP).
**ש: מה קורה ב-3-way handshake ולמה זה חשוב לסורק?**
ת: SYN → SYN-ACK → ACK. Nmap מנצל זאת: סריקת SYN (`-sS`) שולחת SYN ולא משלימה — מהירה ו"חצי-שקטה".
**ש: מה ההבדל בין פורט 80 ל-443?** ת: 80 = HTTP (גלוי), 443 = HTTPS (מוצפן TLS).

### 🔹 סריקה ואיסוף
**ש: איזו פקודת Nmap תריץ קודם ולמה?**
ת: `nmap -sV -sC -p- <IP>` — כל הפורטים (`-p-`), זיהוי גרסאות (`-sV`) וסקריפטים בסיסיים (`-sC`). קודם גילוי מלא, אחר כך העמקה בפורטים שנמצאו.
**ש: מצאת פורט 445 פתוח. מה הצעד הבא?**
ת: SMB — אבדוק גרסה וחולשות ידועות (EternalBlue/MS17-010), אריץ `enum4linux` / `smbclient -L` למשאבים משותפים ומשתמשים.

### 🔹 Web (OWASP)
**ש: הסבר SQL Injection ואיך מונעים.**
ת: קלט משתמש משורשר לשאילתה ומשנה את הלוגיקה (למשל `' OR '1'='1`). מניעה: **Prepared Statements / Parameterized Queries**, ולידציה, הרשאות DB מינימליות.
**ש: ההבדל בין Stored ל-Reflected XSS?**
ת: Reflected — הסקריפט חוזר מיידית מהבקשה (קישור זדוני). Stored — נשמר בשרת ומוגש לכל מבקר (מסוכן יותר). מניעה: Output Encoding + CSP.
**ש: מה זה IDOR?** ת: Insecure Direct Object Reference — גישה למשאב של משתמש אחר ע"י שינוי מזהה (`?id=1`→`?id=2`) כשאין בדיקת הרשאה. מניעה: בדיקת בעלות בצד שרת.

### 🔹 ניצול והסלמת הרשאות
**ש: השגת shell כמשתמש רגיל. איך תסלים הרשאות ב-Linux?**
ת: אריץ `sudo -l`, אחפש SUID (`find / -perm -4000 2>/dev/null`), משימות cron, kernel exploits, קבצי config עם סיסמאות. אצליב מול [GTFOBins](https://gtfobins.github.io).
**ש: ומה ב-Windows?**
ת: הרשאות שירות לא תקינות, AlwaysInstallElevated, סיסמאות ב-registry/קבצים, token impersonation. כלי: WinPEAS, `whoami /priv`.
**ש: מה ההבדל בין Bind ל-Reverse Shell ולמה Reverse עדיף?**
ת: Bind — היעד מאזין, התוקף מתחבר. Reverse — היעד **מתקשר החוצה** לתוקף. Reverse עדיף כי Firewall בד"כ חוסם חיבורים נכנסים אך מתיר יוצאים.

### 🔹 סיסמאות והצפנה
**ש: ההבדל בין Encoding, Hashing ו-Encryption?**
ת: Encoding (Base64) — הפיך, לא אבטחה. Hashing (SHA-256) — חד-כיווני, לאימות שלמות/סיסמאות. Encryption — הפיך עם מפתח, לסודיות.
**ש: מה זה Salt ולמה הוא חשוב?**
ת: ערך אקראי שמתווסף לסיסמה לפני Hashing — מונע שימוש בטבלאות Rainbow וגורם לסיסמאות זהות לקבל hash שונה.
**ש: ההבדל בין מתקפת סיסמה Online ל-Offline?**
ת: Online (Hydra) — מול שירות חי, איטי ורועש. Offline (John/Hashcat) — על hash שחילצנו, מהיר, בלי קשר לרשת.

### 🔹 Active Directory
**ש: מה זה Kerberoasting?**
ת: בקשת כרטיסי Kerberos (TGS) לחשבונות שירות, שחולצים עם hash הניתן לפיצוח offline — כי מוצפנים במפתח הנגזר מסיסמת החשבון. מניעה: סיסמאות שירות חזקות + gMSA.
**ש: מה זה Pass-the-Hash?**
ת: אימות מול שירות עם ה-**NTLM hash** ישירות, בלי לדעת את הסיסמה המקורית.

## חלק ב' — משימות מעשיות שעלולים לבקש (Hands-On)

מעסיקים רבים נותנים מכונה או מסך-שיתוף. התאמנו על אלה:

1. **"הנה IP — תמצא דרך פנימה."** הראה מתודולוגיה: `nmap -sV -sC -p-` → זיהוי שירות פגיע → `searchsploit` → ניצול → shell. **דבר בקול** תוך כדי.
2. **"הנה hash — תפצח אותו."** `hashid`/`hash-identifier` → בחירת מצב Hashcat (`-m`) או John → rockyou → התוצאה.
3. **"יש לך shell כ-`www-data`. תגיע ל-root."** `sudo -l` → SUID → cron → GTFOBins.
4. **"מצא SQLi בטופס הזה."** `' OR 1=1--` → הדגמת עקיפת התחברות → שליפת נתונים → המלצה (Prepared Statements).
5. **"כתוב לי finding אחד."** כותרת → חומרה/CVSS → תיאור → PoC → השפעה → תיקון. (ראה מודול 16.)

> 💡 היעדים המקומיים שבנית בקורס (`owasp_playground.py`, `privesc_lab.sh`, `hashes.txt`...) הם **בדיוק** אימון למשימות האלה. תרגל עליהם עד שהזרימה אוטומטית.

## חלק ג' — שאלות התנהגותיות (Behavioral)

- **"ספר על פעם שפרצת משהו."** → בחר מכונה מה-Portfolio, ספר את השרשרת ב-3 משפטים.
- **"איך אתה נשאר מעודכן?"** → THM/HTB, בלוגים (PortSwigger, HackerOne reports), Twitter/X infosec, CVEs.
- **"מצאת חולשה קריטית בלקוח — מה אתה עושה?"** → מתעד, **מדווח מיד** לאיש הקשר שהוגדר, לא מנצל מעבר ל-Scope, שומר על סודיות.
- **"מה תעשה אם תחרוג מה-Scope בטעות?"** → עוצר מיד, מדווח ללקוח, מתעד. **אתיקה מעל הכל.**
