# 🌍 מעבדות עולם-אמיתי — מסלול מעשי לכל מודול

> **למה הקובץ הזה קיים?** לכל מודול כבר יש **יעד פגיע מקומי** (ה-🎬 הדגמות). הקובץ הזה מוסיף את השכבה הבאה: **מעבדות חיצוניות, חינמיות, בדפדפן** — חדרים (Rooms) ומכונות (Boxes) שסטודנטים פותרים בעצמם כדי לצבור **ניסיון אמיתי שאפשר להציג למעסיק**. כל חדר שמסיימים = שורה ב-Portfolio.

> ⚠️ **חוקי וחשוב:** כל הפלטפורמות כאן הן **סביבות תרגול חוקיות ומוכרות** — מותר ואף רצוי לתקוף בהן. לעולם אל תפנו כלי תקיפה ליעד שאינו שלכם ושאין לכם עליו הרשאה כתובה.

## 🗺️ המפה — מודול אחרי מודול

לכל מודול: **מתחילים כאן** (חדר אחד חובה, קל-בינוני) → **העמקה** (רשות) → **✅ הוכחת יכולת** (מה לצרף ל-Portfolio).

---

### מודול 01 — מבוא, המעבדה ומתודולוגיה
- **מתחילים כאן:** THM — [*Intro to Offensive Security*](https://tryhackme.com/room/introtooffensivesecurity) · [*Starting Out In Cyber Sec*](https://tryhackme.com/room/startingoutincybersec)
- **העמקה:** THM — *Pentesting Fundamentals* · *Principles of Security*
- ✅ **הוכחת יכולת:** צילום מסך של החדר שהושלם + פסקה: "זיהיתי את חמשת שלבי ההאקינג האתי בפועל."

### מודול 02 — יסודות Linux
- **מתחילים כאן:** [**OverTheWire — Bandit**](https://overthewire.org/wargames/bandit/) שלבים 0→15 (פיצוח Linux דרך SSH, ממכר)
- **העמקה:** THM — *Linux Fundamentals Part 1/2/3* · אתר [cmdchallenge.com](https://cmdchallenge.com)
- ✅ **הוכחת יכולת:** הגעה לשלב 15+ ב-Bandit; רשום אילו פקודות (`grep`, `find`, `ssh`, `nc`) פתרו כל שלב.

### מודול 03 — יסודות רשתות
- **מתחילים כאן:** THM — [*Intro to Networking*](https://tryhackme.com/room/introtonetworking) · *What is Networking?*
- **העמקה:** THM — *Network Services* · *Network Services 2* · *Wireshark: The Basics*
- ✅ **הוכחת יכולת:** צילום לכידת סיסמה בטקסט גלוי ב-Wireshark (FTP/HTTP), עם הסבר איזה פרוטוקול חשף אותה.

### מודול 04 — סקריפטינג: Bash ו-Python
- **מתחילים כאן:** THM — [*Bash Scripting*](https://tryhackme.com/room/bashscripting) · *Python Basics*
- **העמקה:** THM — *Python for Pentesters* · תרגילי [HackerRank](https://www.hackerrank.com) / [Codewars](https://www.codewars.com)
- ✅ **הוכחת יכולת:** העלו ל-GitHub סקריפט שלכם (port-scanner או brute-forcer מהמודול) עם README.

### מודול 05 — איסוף מידע (Reconnaissance)
- **מתחילים כאן:** THM — [*Passive Reconnaissance*](https://tryhackme.com/room/passiverecon) · *Active Reconnaissance*
- **העמקה:** THM — *OSINT* · *Google Dorking* · *Shodan.io* · [תרגילי OSINT ב-TraceLabs](https://www.tracelabs.org)
- ✅ **הוכחת יכולת:** דוח OSINT קצר על דומיין ציבורי (רק מידע פומבי!) — subdomains, טכנולוגיות, כתובות מייל.

### מודול 06 — סריקה, מיפוי והערכת חולשות
- **מתחילים כאן:** THM — [*Nmap*](https://tryhackme.com/room/furthernmap) (סדרת ה-Nmap: Host Discovery → Basic → Advanced Port Scans)
- **העמקה:** THM — *Enumeration* · **HTB — Starting Point (Tier 0)**
- ✅ **הוכחת יכולת:** פלט Nmap מלא על מכונת תרגול + טבלת פורטים/שירותים/גרסאות שמילאתם.

### מודול 07 — ניצול והשגת גישה (Exploitation)
- **מתחילים כאן:** THM — [*Metasploit: Introduction*](https://tryhackme.com/room/metasploitintro) → *Exploitation* → *Meterpreter*
- **העמקה:** THM — [*Blue*](https://tryhackme.com/room/blue) (EternalBlue, קלאסיקה!) · *Ice* · *Blaster* · **HTB Starting Point: Tier 1**
- ✅ **הוכחת יכולת:** Shell כ-SYSTEM/root על מכונת תרגול + תיאור שרשרת: סריקה → חולשה → ניצול → גישה.

### מודול 08 — מתקפות סיסמאות (Password Attacks)
- **מתחילים כאן:** THM — [*Crack the Hash*](https://tryhackme.com/room/crackthehash) · *Hydra* · *John The Ripper*
- **העמקה:** THM — *Password Attacks* · אתגרי hash ב-PicoCTF
- ✅ **הוכחת יכולת:** צילום פיצוח מוצלח של hash עם John/Hashcat + זיהוי סוג ה-hash עם `hashid`.

### מודול 09 — אבטחת Web (OWASP Top 10)
- **מתחילים כאן:** [**PortSwigger Web Security Academy**](https://portswigger.net/web-security/all-labs) — התחילו ב-SQL injection ו-XSS (עשרות מעבדות חינם)
- **העמקה:** THM — *OWASP Top 10* · *OWASP Juice Shop* · [**OverTheWire — Natas**](https://overthewire.org/wargames/natas/)
- ✅ **הוכחת יכולת:** 5+ מעבדות PortSwigger שהושלמו (SQLi, XSS, IDOR, Auth) — PortSwigger מתעד התקדמות בפרופיל.

### מודול 10 — Buffer Overflow
- **מתחילים כאן:** THM — [*Buffer Overflow Prep*](https://tryhackme.com/room/bufferoverflowprep) (Tib3rius, סגנון OSCP)
- **העמקה:** THM — *Brainstorm* · *Gatekeeper* · [**exploit.education — Protostar**](https://exploit.education/protostar/) · pwn.college
- ✅ **הוכחת יכולת:** תיעוד 7 שלבי ה-BOF (fuzzing → offset → EIP → bad chars → JMP ESP → shellcode → shell).

### מודול 11 — פוסט-אקספלויטציה והסלמת הרשאות
- **מתחילים כאן:** THM — [*Linux PrivEsc*](https://tryhackme.com/room/linuxprivesc) · *Windows PrivEsc*
- **העמקה:** THM — *Linux PrivEsc Arena* · *Windows PrivEsc Arena* · אתרי עזר: [GTFOBins](https://gtfobins.github.io) · [LOLBAS](https://lolbas-project.github.io)
- ✅ **הוכחת יכולת:** הסלמה ל-root/SYSTEM בשלושה וקטורים שונים (SUID, sudo, cron/service) עם הסבר לכל אחד.

### מודול 12 — Pivoting ותנועה רוחבית
- **מתחילים כאן:** THM — [*Wreath*](https://tryhackme.com/room/wreath) (רשת שלמה עם Pivoting — החדר המושלם למודול הזה)
- **העמקה:** THM — *Holo* · שימוש ב-`proxychains`, `chisel`, `ssh -L`
- ✅ **הוכחת יכולת:** דיאגרמת רשת שמראה כיצד הגעתם ממכונה חשופה למכונה פנימית דרך tunnel.

### מודול 13 — Active Directory
- **מתחילים כאן:** THM — [*Attacktive Directory*](https://tryhackme.com/room/attacktivedirectory) · *Active Directory Basics*
- **העמקה:** THM — *Post-Exploitation Basics* · *Throwback* (רשת AD) · **HTB — Forest** (retired, יש Walkthroughs)
- ✅ **הוכחת יכולת:** שרשרת AD מתועדת: LLMNR poisoning → Kerberoasting → פיצוח → Domain Admin.
- ⚠️ דורש זיכרון רב — השתמשו ב-**ענן (TryHackMe)**, לא במכונה מקומית (ראה הערת 8GB RAM במדריך המעבדה).

### מודול 14 — תקיפות אלחוטיות (Wireless)
- **מתחילים כאן:** THM — [*Wifi Hacking 101*](https://tryhackme.com/room/wifihacking101) · פיצוח offline של קובץ `wpa.cap` הרשמי (סיסמה: `biscotte`)
- **העמקה:** aircrack-ng [captures לדוגמה](https://www.aircrack-ng.org/doku.php?id=wep_cracking) · WiFi Challenge Lab
- ✅ **הוכחת יכולת:** פיצוח handshake של WPA עם `aircrack-ng -w` ורשימת מילים.
- ⚠️ תקיפה חיה דורשת מתאם Wi-Fi עם Monitor Mode — ללא חומרה, התרגול הוא offline בלבד.

### מודול 15 — הנדסה חברתית ופישינג
- **מתחילים כאן:** THM — [*Phishing*](https://tryhackme.com/room/phishingyl) · *The Greenholt Phish*
- **העמקה:** THM — *Social Engineering* · הקמת קמפיין ב-[GoPhish](https://getgophish.com) (במעבדה מבודדת בלבד!)
- ✅ **הוכחת יכולת:** ניתוח מייל פישינג אמיתי — זיהוי האינדיקטורים (דומיין, דחיפות, קישור), + דוח קצר.

### מודול 16 — כתיבת דוח (Reporting)
- **מתחילים כאן:** כתבו דוח חדירה מלא על **אחת המכונות שפתרתם** (THM/HTB) — recon → ממצאים → CVSS → המלצות
- **העמקה:** עיינו בדוחות לדוגמה: [TCM Security Sample Report](https://github.com/hmaverickadams/TCM-Security-Sample-Pentest-Report) · [Offensive Security Sample Report](https://www.offensive-security.com/reports/sample-penetration-testing-report.pdf)
- ✅ **הוכחת יכולת:** דוח PDF מקצועי אחד — **זהו פריט ה-Portfolio החשוב ביותר למעסיק.**

## 🏆 מסלול ה-Capstone — "אפס עד Domain Admin"

אחרי שסיימתם את כל המודולים, הוכיחו שליטה מקצה-לקצה:

1. **THM — [Wreath](https://tryhackme.com/room/wreath)** — רשת שלמה: web exploit → pivot → תנועה רוחבית.
2. **HTB — Starting Point (כל ה-Tiers)** — מסלול מודרך של פריצה מודרנית.
3. **אתגר הגמר:** פתרו מכונה **ללא Walkthrough**, תעדו הכל, וכתבו דוח מלא (מודול 16).

> ✅ **סיום:** סטודנט שמסיים את המסלול הזה מחזיק **5–10 דוחות ומכונות פתורות** — בדיוק מה שמעסיק רוצה לראות בראיון למשרת Junior Penetration Tester / SOC Analyst.
