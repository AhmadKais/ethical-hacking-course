# 🔥 מדריך הוראה מעשית — איך להפוך את הקורס למרתק

> מדריך למרצה. המטרה: להעיף שעמום מהכיתה. הרעיון המרכזי — **לא מלמדים פקודות, מפצחים איתן**. הסטודנט לומד `grep` כי היא פותחת את השלב הבא במשחק, לא כי אמרת לו.

---

## העיקרון: קודם ריגוש, אחר כך תיאוריה (Hook → Hack → Understand)

הסדר הקלאסי — "היום נלמד את מודל OSI" — הורג את הכיתה. הפוך אותו:

1. **Hook (וו):** פותחים כל שיעור ב-**הדגמה מרשימה** או **אתגר** — משהו שגורם לסטודנט לומר *"וואו, אני רוצה לדעת לעשות את זה"*.
2. **Hack (עשייה):** הסטודנט **מבצע** בעצמו, מיד, בידיים — מנצח אתגר, לוכד דגל, גונב סיסמה.
3. **Understand (הבנה):** רק **אחרי** שהוא ראה את התוצאה — מסבירים *למה* זה עבד (כאן נכנסת התיאוריה, ועכשיו יש לה הקשר ומוטיבציה).

> 💡 כלל אצבע: אם סטודנט ישאל "מתי נעשה משהו אמיתי?" — כבר איחרת. תן לו ניצחון קטן **בעשר הדקות הראשונות** של כל שיעור.

הדגמה חיה של 5 דקות שגורמת ללסתות ליפול, ואז לומדים איך היא עבדה:

- **גניבת סיסמה מהאוויר (מודול 3):** פתח **Wireshark**, התחבר ל-FTP/HTTP לא-מוצפן במעבדה, והראה את **הסיסמה בטקסט גלוי** רצה ברשת. הכיתה נדלקת → עכשיו הם רוצים ללמוד רשתות.

- **סיסמה שנפרצת בשניות (מודול 8):** קח hash של `password` והרץ `john` — נפרץ מיד. "ככה נראית סיסמה חלשה."
- **`admin/admin` פותח מצלמה (מודול 1):** ספר על Mirai והראה מנוע חיפוש Shodan עם מכשירים חשופים.

## 🕶️ אווירת "האקר" — דופמין קטן שמושך סטודנטים

כלים שלא משנים כלום מקצועית — אבל גורמים לסטודנט להרגיש כמו בסרט, וזה **מושך**. הרץ אותם בשיעור הראשון:

```bash
sudo apt install cmatrix hollywood cowsay figlet lolcat sl -y
cmatrix              # "מטריקס" יורד על המסך
hollywood            # מסך פריצה הוליוודי מזויף — מושלם להפסקה
figlet HACKER | lolcat   # כותרת צבעונית
```

וגם כלים מודרניים שבאמת משדרגים את חוויית ה-Terminal:

```bash
sudo apt install bat fzf tldr -y
bat file.txt         # cat עם צבעים ומספרי שורות
tldr tar             # דוגמאות שימוש במקום man ארוך
fzf                  # חיפוש אינטראקטיבי מהיר
```

## 📋 מסלול הוראה מומלץ — פרקטי-תחילה

לכל מודול, במקום "הרצאה ואז תרגול", הרץ כך:

1. **10 דק' — Hook:** הדגמה/אתגר פתיחה.
2. **15 דק' — תיאוריה ממוקדת:** רק מה שצריך כדי לנצח את האתגר של היום.
3. **60 דק' — מעבדה/משחק:** הסטודנטים בידיים, אתה מסתובב ועוזר. **רוב הזמן כאן.**
4. **5 דק' — סיכום:** מה פיצחנו היום, ומה מחכה מחר.

> יחס הזהב: **80% ידיים על המקלדת, 20% הרצאה.** אם אתה מדבר יותר מ-20 דקות ברצף — עצור, תן אתגר.
