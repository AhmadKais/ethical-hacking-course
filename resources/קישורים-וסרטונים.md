# 🔗 קישורים וסרטונים — מאגר משאבים ללמידה עצמית

> אוסף מרוכז של **אתרים, ערוצי יוטיוב, כלים וחומרי עזר** מהשורה הראשונה בתחום. רובם **באנגלית** (שפת המקצוע) — חשיפה אליהם היא חלק מההכשרה לשוק העבודה. שמור את העמוד הזה כ-Bookmark.

> ⚠️ כל הכלים והטכניקות מיועדים לשימוש **חוקי בלבד** — על מערכות שבבעלותך או בסביבות תרגול מוכרות.

## 🧪 פלטפורמות תרגול (Hands-On)

- [**TryHackMe**](https://tryhackme.com) — חדרים מודרכים בדפדפן. המקום להתחיל בו.
- [**HackTheBox**](https://www.hackthebox.com) — מכונות מאתגרות + [Academy](https://academy.hackthebox.com) ללמידה מובנית.
- [**PortSwigger Web Security Academy**](https://portswigger.net/web-security) — המעבדות הטובות בעולם ל-Web, חינם לגמרי.
- [**OverTheWire**](https://overthewire.org/wargames/) — Wargames קלאסיים (Bandit ל-Linux, Natas ל-Web).
- [**PentesterLab**](https://pentesterlab.com) — תרגילי Web ו-PrivEsc ממוקדים.
- [**VulnHub**](https://www.vulnhub.com) — מכונות וירטואליות פגיעות להורדה ולתקיפה מקומית.
- [**PicoCTF**](https://picoctf.org) — תחרות CTF למתחילים, זמינה תמיד.
- [**Hack The Box — Starting Point**](https://app.hackthebox.com/starting-point) — מסלול פריצה מודרך למתחילים.

> 📋 מיפוי מלא של חדרים ספציפיים לכל מודול: ראה [**מעבדות עולם-אמיתי**](מעבדות-עולם-אמיתי.md).
