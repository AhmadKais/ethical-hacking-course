# 🏫 בקשת התקנה למחלקת ה-IT — מעבדת קורס האקינג אתי

מסמך זה מיועד למחלקת ה-IT של המכללה. הוא מפרט את התוכנות והמשאבים הנדרשים להרצת קורס בדיקות חדירה (Penetration Testing) על עמדות המעבדה.

> ⚠️ **הנקודה הקריטית — התקנה קבועה (Persistence):** אם העמדות משתמשות בתוכנת "הקפאה"/שחזור-באתחול (למשל **Deep Freeze / Faronics / Reboot Restore Rx / Windows SteadyState**), כל ההתקנות **יימחקו בכל כיבוי**. לכן יש להתקין הכל במצב **"מופשר" (Thawed)** ולצרוב מחדש לתמונת הבסיס (Base Image), **או** לאחסן את מכונות ה-VM בכונן/מחיצה **שאינם מוקפאים**.

---

| דרישה | פירוט |
|-------|-------|
| **וירטואליזציה ב-BIOS** | להפעיל **Intel VT-x** / **AMD-V** ב-BIOS/UEFI (חובה — בלעדיה לא רצות מכונות VM) |
| **RAM** | 8GB מינימום, **16GB מומלץ** (הכרחי למודול Active Directory) |
| **דיסק פנוי** | **100GB+** פנויים לאחסון מכונות ה-VM |

## 4. אסטרטגיית קביעוּת (Persistence) — בחרו אחת

- **אפשרות א' (מומלץ):** התקינו הכל + ייבאו את מכונות ה-VM במצב מופשר, ואז **צרבו מחדש את תמונת הבסיס** של העמדות. הכל יהיה חלק מהמצב המשוחזר.
- **אפשרות ב':** הגדירו **מחיצה/כונן שאינם מוקפאים** (למשל `D:`) לאחסון קובצי ה-VM; תוכנת ה-VirtualBox עצמה בתמונת הבסיס המוקפאת.
- **אפשרות ג':** אחסנו את דמויות ה-VM ב**שרת קבצים/שיתוף רשת**, והתלמידים מריצים/מעתיקים מהשיתוף.

> 💡 שינויים שתלמידים עושים **בתוך** ה-VM המוקפא ממילא מתאפסים באתחול — וזה לרוב **רצוי** (סביבה נקייה לכל שיעור). אם רוצים לשמור עבודת תלמידים — יש לאחסן את ה-VMs באחסון לא-מוקפא.

---

## 5. רשת והרשאות

- **רשת מבודדת:** להגדיר ב-VirtualBox מתאם **Host-Only** (כדי שהמכונות יראו זו את זו ללא חשיפה לרשת המכללה). ההגדרה צריכה להיות חלק מהתמונה הקבועה.
- **גישה לאינטרנט:** נדרשת לעדכוני `apt`, הורדת מטרות, ומעבדות ענן. ייתכן שיידרש לאשר תעבורה ב-Firewall/Proxy.
- **הרשאות:** לאשר את VirtualBox/VMware ב-Endpoint Protection/Antivirus של המכללה (כלי אבטחה עלולים לחסום).

## 6. חלופה שמייתרת את הכל — מעבדות ענן ☁️

אם התקנת VM על העמדות מורכבת מדי (הקפאה, חומרה חלשה, מדיניות נעילה), ניתן להעביר את **כל** התרגול המעשי ל**דפדפן** דרך:
- **[TryHackMe](https://tryhackme.com)** — Kali ומכונות מטרה בדפדפן, ללא התקנה כלל.
- **[HackTheBox](https://www.hackthebox.com)** — מכונות מאתגרות בענן.

במקרה זה, **הדרישה היחידה מ-IT היא דפדפן מודרני + גישה לאתרים אלה**. זו האופציה הכי פשוטה לתחזוקה במעבדת מכללה.

## נספח — התקנת VirtualBox עדכני (קרנל Linux חדש)

אם עמדות המעבדה מריצות Linux עם קרנל חדש, גרסת ה-VirtualBox ממאגר ההפצה עלולה להיכשל בבניית המודול (`vboxdrv`). התקנה נכונה:
```bash
sudo apt remove --purge virtualbox virtualbox-dkms virtualbox-qt -y
wget -O- https://www.virtualbox.org/download/oracle_vbox_2016.asc | sudo gpg --dearmor -o /usr/share/keyrings/oracle-vbox-2016.gpg
echo "deb [arch=amd64 signed-by=/usr/share/keyrings/oracle-vbox-2016.gpg] https://download.virtualbox.org/virtualbox/debian $(lsb_release -cs) contrib" | sudo tee /etc/apt/sources.list.d/virtualbox.list
sudo apt update && sudo apt install virtualbox-7.1 -y
sudo /sbin/vboxconfig
```
