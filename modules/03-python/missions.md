## משימה 2 — עיבוד Banner של שירות 🟢

**מטרה:** לתרגל פעולות על מחרוזות (Strings) — כפי שנעשה בעת ניתוח פלט.

```python
banner = "Apache/2.4.49 (Debian)"

# השלם: הדפס את שם השרת בלבד (Apache)
# רמז: השתמש ב-split
print(banner.split("/")[0])

# השלם: בדוק אם המחרוזת מכילה "2.4.49"
print("2.4.49" in banner)
```

**✅ קריטריון הצלחה:** הפלט הוא `Apache` ואז `True`.

**❓ שאלה:** כיצד היית מחלץ **רק** את מספר הגרסה (`2.4.49`)?

## משימה 3 — לולאה על רשימת פורטים 🟡

**מטרה:** לתרגל רשימות (Lists) ולולאות.

```python
ports = [21, 22, 80, 443, 445]
services = {21: "FTP", 22: "SSH", 80: "HTTP", 443: "HTTPS", 445: "SMB"}

for port in ports:
    print(f"Port {port} -> {services[port]}")
```

**✅ קריטריון הצלחה:** הודפסו 5 שורות המקשרות פורט לשירות.

**מיני-אתגר:** הוסף לרשימה את פורט `3389` ואת `RDP` למילון, ובדוק שהלולאה מדפיסה אותו נכון.

## משימה 4 — הרצת סורק הפורטים 🟡

**מטרה:** להריץ ולהבין את הכלי האמיתי מהמודול.

1. העתק את קוד **סורק הפורטים** מ-[חומר הלימוד](README.md#38-פרויקט-סורק-פורטים-building-a-port-scanner) לקובץ `scanner.py`.
2. הרץ אותו על עצמך:
```bash
python3 scanner.py
```
3. בטרמינל אחר, הפעל שירות מקומי כדי לראות פורט נפתח:
```bash
python3 -m http.server 8080   # מפעיל שרת web על פורט 8080
```
4. שנה את הטווח בסקריפט ל-`range(8000, 8100)` והרץ שוב.

**✅ קריטריון הצלחה:** הסורק דיווח `Port 8080 is OPEN`.

> ⚠️ הרץ **אך ורק** על `127.0.0.1` או על מכונות המעבדה שלך.

## 🔴 אתגר מסכם — "שדרוג הסורק"

שדרג את סורק הפורטים כך שיכלול:

1. **קלט מהמשתמש** — קבל את כתובת היעד עם `input()` במקום ערך קבוע.
2. **שם השירות** — לצד כל פורט פתוח, הדפס את שם השירות (מתוך מילון `services`).
3. **סיכום** — בסוף הריצה הדפס: `[*] Scan complete. Found N open ports.`
4. **(בונוס)** מדוד את זמן הסריקה עם המודול `time`.

**דוגמת פלט רצויה:**
```
[*] Enter target: 127.0.0.1
[+] Port 80  is OPEN (HTTP)
[+] Port 8080 is OPEN
[*] Scan complete. Found 2 open ports in 3.4s
```
