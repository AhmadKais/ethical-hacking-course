# יסודות רשתות
## מודול 2 — Networking Fundamentals

- מודל OSI ומחסנית TCP/IP
- TCP מול UDP ולחיצת היד
- פורטים ופרוטוקולים נפוצים
- כתובות IP ו-Subnetting

## מודל OSI — 7 שכבות

- **7 Application** — HTTP, DNS, FTP
- **6 Presentation** — TLS/SSL
- **5 Session** — RPC, NetBIOS
- **4 Transport** — TCP, UDP
- **3 Network** — IP, ICMP
- **2 Data Link** — Ethernet, ARP
- **1 Physical** — כבלים, Wi-Fi

## TCP מול UDP

- **TCP** — אמין, מבוסס-חיבור, לחיצת יד
- **UDP** — מהיר, ללא חיבור, "יורה ושוכח"
- TCP: דפדוף, מייל, קבצים
- UDP: DNS, סטרימינג, VoIP

## לחיצת יד תלת-שלבית

- **1. SYN** — הלקוח מבקש חיבור
- **2. SYN-ACK** — השרת מאשר
- **3. ACK** — החיבור נפתח
- 🔍 בסיס לסריקת פורטים: SYN-ACK = פתוח, RST = סגור

## פורטים נפוצים

- **21** FTP · **22** SSH · **23** Telnet
- **25** SMTP · **53** DNS
- **80** HTTP · **443** HTTPS
- **139/445** SMB · **3389** RDP
- זיהוי פורטים = מיפוי משטח התקיפה

## כתובות IP

- **IPv4** — `192.168.1.10` (32 סיביות)
- **IPv6** — פורמט חדש (128 סיביות)
- **פרטיות:** 10.x / 172.16-31.x / 192.168.x
- **MAC** — כתובת פיזית (ניתנת לזיוף)

## Subnetting ו-CIDR

- חלוקת רשת לתת-רשתות
- **`/24`** = 256 כתובות (255.255.255.0)
- **`/16`** = 65,536 · **`/8`** = ~16.7M
- דוגמה: `nmap 192.168.1.0/24`

## פרוטוקולי עזר

- **DNS** — שם ← כתובת IP
- **ARP** — IP ← MAC (בסיס ל-MITM)
- **ICMP** — `ping`, בדיקת מארח חי
- **DHCP** — חלוקת כתובות אוטומטית

## סיכום מודול 2

- OSI ו-TCP/IP מתארים תקשורת ברשת
- TCP אמין, UDP מהיר
- פורטים = דלתות השירותים
- IP + Subnetting = גבולות הרשת שנסרוק
- **תרגול:** `ip a`, `ping`, Wireshark
