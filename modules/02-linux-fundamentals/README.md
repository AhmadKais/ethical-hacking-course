## 2.1 השֶׁל (Shell) ושורת הפקודה

**השֶׁל (Shell)** הוא התוכנית שמפרשת את הפקודות שאתה מקליד. ב-Kali ברירת המחדל היא **Bash** (וכיום לעיתים ZSH). ה-**Terminal** הוא החלון שבו אתה מקליד.

### אנטומיה של ה-Prompt
```text
┌──(kali㉿kali)-[~]
└─$
```
- `kali` — שם המשתמש
- `kali` (אחרי הסימן) — שם המחשב (Hostname)
- `~` — התיקייה הנוכחית (`~` = תיקיית הבית)
- `$` — משתמש רגיל · `#` — משתמש-על (root)

> 💡 **טיפים שיחסכו לך זמן:**
> - **Tab** — השלמה אוטומטית של שמות קבצים/פקודות.
> - **↑ / ↓** — מעבר בין פקודות קודמות.
> - **`history`** — כל הפקודות שהרצת. `!42` מריץ מחדש את פקודה מס' 42.
> - **`clear`** (או `Ctrl+L`) — ניקוי המסך.
> - **`man <פקודה>`** — המדריך המלא של כל פקודה (`q` ליציאה).

## 2.2 מבנה מערכת הקבצים (Filesystem Hierarchy)

ב-Linux **הכל הוא קובץ**, והכל מתחיל מהשורש `/` (Root). אין "כונן C:" — יש עץ אחד.

| נתיב | תפקיד | רלוונטיות לתקיפה |
|------|-------|------------------|
| `/` | השורש — ראש העץ | — |
| `/etc` | קובצי הגדרות המערכת | `/etc/passwd`, `/etc/shadow` — יעדים חמים |
| `/home` | תיקיות המשתמשים | קבצים אישיים, מפתחות SSH |
| `/root` | תיקיית הבית של root | פרס גדול אם מגיעים לשם |
| `/var` | לוגים ונתונים משתנים | `/var/www` (אתרים), `/var/log` (לוגים) |
| `/tmp` | קבצים זמניים | מקום נוח להעלות כלים בזמן תקיפה |
| `/usr` | תוכנות וספריות | `/usr/share/wordlists` |
| `/bin`, `/sbin` | פקודות מערכת | הכלים עצמם |
| `/opt` | תוכנות שהותקנו ידנית | כלים שהורדנו מ-GitHub |

> 🔍 **שני קבצים שכל האקר מכיר:**
> - `/etc/passwd` — רשימת המשתמשים (קריא לכולם).
> - `/etc/shadow` — ה-Hash של הסיסמאות (קריא ל-root בלבד). גישה אליו = פרס.

## 2.3 ניווט (Navigation)

```bash
pwd                 # Print Working Directory — איפה אני עכשיו
ls                  # רשימת קבצים בתיקייה
ls -l               # פירוט מלא (הרשאות, בעלים, גודל, תאריך)
ls -la              # כולל קבצים מוסתרים (שמתחילים ב-.)
ls -lh              # גדלים בפורמט קריא (KB/MB)
cd /etc             # מעבר לתיקייה (נתיב מוחלט)
cd Downloads        # מעבר לתת-תיקייה (נתיב יחסי)
cd ..               # תיקייה אחת אחורה (הורה)
cd ~                # לתיקיית הבית
cd -                # חזרה לתיקייה הקודמת
tree                # תצוגת עץ של התיקיות
```

### נתיב מוחלט מול יחסי
- **מוחלט (Absolute):** מתחיל מ-`/`, למשל `/home/kali/Desktop`. עובד מכל מקום.
- **יחסי (Relative):** ביחס למיקום הנוכחי, למשל `Desktop` או `../etc`.
- קיצורים: `.` = התיקייה הנוכחית · `..` = ההורה · `~` = הבית.

> 💡 **דוגמה:** אם אתה ב-`/home/kali` והרצת `cat ../../etc/passwd` — `..` פעמיים מעלה אותך ל-`/`, ומשם ל-`etc/passwd`.

## 2.4 עבודה עם קבצים ותיקיות

```bash
touch file.txt          # יצירת קובץ ריק
mkdir mydir             # יצירת תיקייה
mkdir -p a/b/c          # יצירת שרשרת תיקיות
cp file.txt copy.txt    # העתקה
cp -r dir1 dir2         # העתקת תיקייה (רקורסיבי)
mv file.txt /tmp/       # העברה
mv old.txt new.txt      # שינוי שם
rm file.txt             # מחיקת קובץ
rm -r mydir             # מחיקת תיקייה
rm -rf mydir            # מחיקה בכוח (זהירות!)
```

> ⚠️ **אזהרה:** ל-Linux אין "סל מיחזור". `rm -rf` מוחק לצמיתות ומיידית. חשוב פעמיים לפני שמריצים אותו, ולעולם לא על `/`.

## 2.5 צפייה ועריכת קבצים

### צפייה
```bash
cat file.txt        # הדפסת כל הקובץ
less file.txt       # צפייה עמוד-עמוד (q ליציאה, / לחיפוש)
head file.txt       # 10 השורות הראשונות
head -n 20 file.txt # 20 שורות ראשונות
tail file.txt       # 10 השורות האחרונות
tail -f /var/log/syslog  # מעקב חי אחרי לוג (שימושי מאוד)
wc -l file.txt      # ספירת שורות
```

### הפניית פלט (Redirection)
```bash
echo "hello" > file.txt     # כתיבה (דורס את הקובץ)
echo "world" >> file.txt    # הוספה בסוף (לא דורס)
command > out.txt 2>&1       # הפניית פלט ושגיאות לקובץ
```

### עריכה — nano (הכי פשוט)
```bash
nano file.txt
# Ctrl+O = שמירה, Ctrl+X = יציאה
```

### עריכה — vim (חזק, נפוץ בשרתים)
```bash
vim file.txt
# i = מצב עריכה (Insert)
# Esc = חזרה למצב פקודות
# :wq = שמירה ויציאה   |   :q! = יציאה ללא שמירה
```

> 💡 **טעות נפוצה:** "נתקעתי ב-vim ואי אפשר לצאת". הפתרון: `Esc` ואז הקלד `:q!` ו-Enter.

## 2.6 משתמשים, קבוצות והרשאות

```bash
whoami          # מי אני
id              # ה-UID, ה-GID והקבוצות שלי
who             # מי מחובר כרגע
cat /etc/passwd # כל המשתמשים במערכת
```

### קריאת שורת הרשאות
כשמריצים `ls -l` רואים משהו כזה:
```text
-rwxr-xr--  1 kali kali  1024 Jan 1 script.sh
```
פירוק ה-`-rwxr-xr--`:
| חלק | משמעות |
|-----|--------|
| `-` | סוג (`-` קובץ, `d` תיקייה, `l` קישור) |
| `rwx` | הרשאות ה**בעלים** (Owner) — קריאה/כתיבה/הרצה |
| `r-x` | הרשאות ה**קבוצה** (Group) |
| `r--` | הרשאות **כולם** (Others) |

- **r** = read (4) · **w** = write (2) · **x** = execute (1)

### שינוי הרשאות ובעלות
```bash
chmod +x script.sh       # הוספת הרשאת הרצה
chmod 755 script.sh      # rwx לבעלים, r-x לשאר (7=rwx,5=r-x)
chmod 644 file.txt       # rw לבעלים, r לשאר
chown kali:kali file.txt # שינוי בעלים וקבוצה
```

> 🔍 **קשר לתקיפה — קבצי SUID:** קובץ עם ביט SUID רץ בהרשאות **הבעלים** שלו, לא של המריץ. אם קובץ בבעלות root מוגדר SUID — ניתן לנצלו להסלמת הרשאות (מודול 11). איתור:
> ```bash
> find / -perm -4000 2>/dev/null
> ```

## 2.7 sudo והרשאות-על

**root** הוא משתמש-העל (UID 0) — יכול הכל. **`sudo`** ("Super User DO") מריץ פקודה יחידה בהרשאות root.

```bash
sudo apt update         # הרצת פקודה כ-root
sudo -l                 # אילו פקודות מותר לי כ-sudo? (חשוב מאוד!)
sudo su                 # מעבר למעטפת root מלאה
whoami                  # (אחרי sudo su → root)
```

- קובץ ההגדרות: `/etc/sudoers` (עורכים עם `visudo`).

> 🔍 **קשר לתקיפה:** `sudo -l` הוא מהדברים הראשונים שבודקים אחרי השגת גישה — הרשאות sudo שגויות הן דרך קלאסית להסלמת הרשאות ל-root (מודול 11).

## 2.8 ניהול חבילות והתקנת כלים

Kali מבוססת Debian, ומשתמשת ב-**APT**:
```bash
sudo apt update                 # רענון רשימת החבילות
sudo apt upgrade -y             # עדכון החבילות
sudo apt install nmap -y        # התקנת כלי
sudo apt remove nmap -y         # הסרה
apt search <keyword>            # חיפוש חבילה
dpkg -i package.deb             # התקנת חבילת .deb ידנית
```

### התקנה מ-GitHub (כלים שאינם ב-APT)
```bash
git clone https://github.com/aboul3la/Sublist3r.git
cd Sublist3r
pip install -r requirements.txt   # התקנת תלויות Python
python3 sublist3r.py -d target.com
```

> 💡 סדר הפעולות הרגיל אחרי התקנת Kali נקייה: `sudo apt update && sudo apt full-upgrade -y`.

## 2.9 ניהול שירותים (Services)

**שירות (Service / Daemon)** הוא תוכנית שרצה ברקע (שרת web, SSH, בסיס נתונים).

```bash
sudo systemctl start ssh       # הפעלת שירות
sudo systemctl stop ssh        # עצירה
sudo systemctl restart ssh     # הפעלה מחדש
sudo systemctl status ssh      # בדיקת מצב
sudo systemctl enable ssh      # הפעלה אוטומטית בעליית המערכת
# תחביר ישן שעדיין עובד:
sudo service apache2 start
```

> 🔍 **דוגמה מעשית:** כדי להעביר קובץ למכונת מטרה, מפעילים שרת web מקומי:
> ```bash
> sudo systemctl start apache2       # מגיש את /var/www/html
> # או שרת פייתון מהיר:
> python3 -m http.server 8000
> ```

## 2.10 פקודות רשת נפוצות

```bash
ip a                 # כתובות IP ו-MAC (מחליף את ifconfig)
ip route             # טבלת הניתוב (Gateway)
ping -c 4 10.0.0.1   # בדיקת קישוריות (4 חבילות)
ss -tuln             # פורטים פתוחים מקומית (מחליף netstat)
netstat -tulnp       # פורטים + התהליכים שמאזינים
cat /etc/resolv.conf # שרת ה-DNS
curl http://10.0.0.5 # שליפת דף web
wget http://.../file # הורדת קובץ
ssh user@10.0.0.5    # התחברות מרוחקת מאובטחת
nslookup google.com  # תרגום שם ל-IP
```

> 💡 את הרשת עצמה (OSI, TCP/UDP, פורטים) נלמד לעומק ב[מודול 3](../03-networking/). כאן המיקוד הוא בפקודות.

## 2.11 תהליכים (Processes)

```bash
ps aux               # כל התהליכים הרצים
ps aux | grep ssh    # סינון לתהליך מסוים
top                  # תצוגה חיה של תהליכים (q ליציאה)
kill 1234            # סיום תהליך לפי PID
kill -9 1234         # סיום בכוח
./script.sh &        # הרצה ברקע
jobs                 # משימות הרקע
```

## 2.12 חיפוש, צינורות וטריקים

### חיפוש
```bash
find / -name "*.conf" 2>/dev/null   # חיפוש קבצים לפי שם
find / -perm -4000 2>/dev/null      # חיפוש קבצי SUID
grep "password" file.txt            # חיפוש טקסט בקובץ
grep -r "api_key" /var/www          # חיפוש רקורסיבי בתיקייה
which nmap                          # היכן נמצא כלי
locate rockyou.txt                  # חיפוש מהיר (דורש updatedb)
```

### צינורות (Pipes) ושרשור
ה-**Pipe** (`|`) מעביר את הפלט של פקודה אחת כקלט לשנייה — כלי עוצמתי:
```bash
cat /etc/passwd | grep root         # רק שורות עם root
ps aux | grep apache | wc -l        # כמה תהליכי apache רצים
cat access.log | grep "404" | sort | uniq -c   # ספירת שגיאות 404
```
- `&&` — הרץ את הבא רק אם הקודם הצליח: `apt update && apt upgrade`
- `;` — הרץ ברצף ללא קשר להצלחה.
- `>` `>>` — הפניית פלט (סעיף 2.5).

> 💡 **דוגמה משולבת מהעולם האמיתי:**
> ```bash
> find / -perm -4000 2>/dev/null | grep -v snap
> ```
> מוצא קבצי SUID לצורך הסלמת הרשאות, ומסנן החוצה רעש — בדיוק מה שעושים אחרי פריצה.
