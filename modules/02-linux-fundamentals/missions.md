## חלק א' — ניווט ומערכת הקבצים (🟢 קל)

**2.1** 🟢 — הצג את התיקייה הנוכחית, עבור ל-`/etc`, והצג את תוכנה.
```bash
pwd
cd /etc
ls
```
  👀 **חפש:** אחרי `cd /etc` הפקודה `pwd` תראה `/etc`, ו-`ls` תציג הרבה קבצי הגדרות (passwd, hosts...).
  ✅ הצלחה: אתה ב-`/etc` ורואה את הקבצים שבו.

**2.2** 🟢 — חזור לתיקיית הבית בשתי דרכים שונות.
```bash
cd ~        # דרך 1: הקיצור לבית
cd          # דרך 2: cd ללא ארגומנט = הביתה
```
  ✅ הצלחה: `pwd` מראה את תיקיית הבית שלך (למשל `/home/kali`).

**2.3** 🟢 — הצג את **כל** הקבצים בבית, כולל מוסתרים, עם פירוט וגדלים קריאים.
```bash
ls -lah
```
  👀 **חפש:** קבצים שמתחילים בנקודה (כמו `.bashrc`) — אלה המוסתרים; ועמודת הגדלים (K/M).
  ✅ הצלחה: אתה רואה גם קבצים מוסתרים עם גדלים.

**2.4** 🟡 — לאיזו מטרה משמשת כל תיקייה? `/etc/passwd` · `/usr/share/wordlists` · `/var/log` · `/root`.
  💡 רמז: README §2.2 — טבלת מבנה מערכת הקבצים.
  ✅ הצלחה: passwd=משתמשים, wordlists=רשימות סיסמאות, /var/log=לוגים, /root=בית של root.

## חלק ב' — קבצים, תיקיות ועריכה (🟢🟡)

**2.5** 🟢 — צור תיקייה `lab` ובתוכה קובץ ריק `notes.txt`.
```bash
mkdir lab
touch lab/notes.txt
ls -l lab
```
  ✅ הצלחה: `ls -l lab` מראה את `notes.txt`.

**2.6** 🟡 — כתוב `recon started` ל-`notes.txt`, ואז **הוסף** שורה `scanning next` בלי לדרוס.
```bash
echo "recon started" > lab/notes.txt     # > דורס/יוצר
echo "scanning next" >> lab/notes.txt     # >> מוסיף בלי לדרוס
cat lab/notes.txt
```
  👀 **חפש:** `cat` מציג **שתי** שורות.
  ✅ הצלחה: שתי השורות קיימות (שים לב ל-`>` מול `>>`).

**2.7** 🟢 — ערוך קובץ עם **nano**, ואז תרגל **יציאה מ-vim** (הפחד הכי גדול של מתחילים — ננצח אותו עכשיו!).
```bash
nano lab/notes.txt
#   הוסף שורה כלשהי, ואז שמור וצא:  Ctrl+O → Enter → Ctrl+X
cat lab/notes.txt        # ודא שהשורה שהוספת נשמרה

vim lab/notes.txt
#   כדי לצאת בלי לשמור:  לחץ Esc, הקלד  :q!  ולחץ Enter
```
  👀 **חפש:** אחרי nano — השורה שהוספת מופיעה ב-`cat`. אחרי vim — חזרת לשורת הפקודה (הצלחת לצאת!).
  ✅ הצלחה: ערכת קובץ ב-nano, ויצאת מ-vim. **זכור לכל החיים:** `Esc` → `:q!` → `Enter` (יציאה בלי שמירה) · `:wq` (שמירה ויציאה).

**2.8** 🟡 — העתק את `notes.txt` ל-`/tmp/`, ואז שנה את שם העותק ל-`backup.txt`.
```bash
cp lab/notes.txt /tmp/
mv /tmp/notes.txt /tmp/backup.txt
ls -l /tmp/backup.txt
```
  ✅ הצלחה: `/tmp/backup.txt` קיים.

**2.9** 🟡 — צור שרשרת תיקיות `project/recon/results` בפקודה אחת.
```bash
mkdir -p project/recon/results
```
  💡 רמז: הדגל `-p` יוצר את כל התיקיות בשרשרת בבת אחת.
  ✅ הצלחה: `ls -R project` מראה את כל שלוש הרמות.

## חלק ג' — הרשאות, משתמשים ו-sudo (🟡🟠)

**2.10** 🟡 — מי אתה? מה ה-UID שלך ובאילו קבוצות אתה?
```bash
id
```
  👀 **חפש:** `uid=`, `gid=`, ו-`groups=`.
  ✅ הצלחה: זיהית את שם המשתמש, ה-UID והקבוצות.

**2.11** 🟡 — צור `run.sh`, הפוך אותו לניתן-הרצה, ואמת ב-`ls -l`.
```bash
touch run.sh
chmod +x run.sh
ls -l run.sh
```
  👀 **חפש:** בעמודת ההרשאות מופיע עכשיו `x` (למשל `-rwxr-xr-x`).
  ✅ הצלחה: ההרשאה `x` נוספה.

**2.12** 🟠 — פענח את שורת ההרשאות `-rwxr-x---`: מה מותר לבעלים, לקבוצה, ולכולם? מה הערך ה-Octal?
  💡 רמז: README §2.6 — סעיף ההרשאות. r=4, w=2, x=1. חלק לשלישיות: בעלים/קבוצה/אחרים.
  ✅ הצלחה: בעלים=rwx(7), קבוצה=r-x(5), אחרים=---(0) → **750**.

**2.13** 🟠 — הרץ `sudo -l`. הסבר למה זו מהפקודות הראשונות של בודק חדירות אחרי שהשיג גישה.
```bash
sudo -l
```
  💡 רמז: README §2.7 — סעיף sudo. זה מראה אילו פקודות מותר להריץ כ-root.
  ✅ הצלחה: הבנת שהרשאות sudo שגויות = מסלול הסלמה ל-root (מודול 11).

## חלק ד' — חבילות, שירותים ורשת (🟡🟠)

**2.14** 🟡 — עדכן את רשימת החבילות והתקן את `tree`.
```bash
sudo apt update
sudo apt install tree -y
tree lab
```
  ✅ הצלחה: `tree` מותקן ומצייר את תיקיית `lab`.

**2.15** 🟡 — הפעל שרת web מקומי על פורט 8000 ואמת מטרמינל אחר.
```bash
python3 -m http.server 8000      # טרמינל 1 (משאיר רץ)
# בטרמינל 2:
curl http://127.0.0.1:8000
```
  👀 **חפש:** בטרמינל 2 מוחזר HTML; בטרמינל 1 מופיעה שורת בקשה `GET /`.
  ✅ הצלחה: השרת עונה. (עצור עם Ctrl+C.)

**2.16** 🟠 — מצא את ה-IP שלך, את ה-Gateway, ובדוק קישוריות אליו.
```bash
ip a                 # ה-IP שלך (inet תחת eth0)
ip route             # ה-Gateway (default via ...)
ping -c 3 <gateway>  # החלף בכתובת ה-Gateway
```
  ✅ הצלחה: יש לך IP + Gateway, וה-ping מקבל תשובות.

**2.17** 🟠 — הצג את כל הפורטים הפתוחים שמאזינים במכונה שלך.
```bash
ss -tulpn
```
  👀 **חפש:** עמודת `LISTEN` — כל שורה היא שירות שמאזין (למשל אם השארת את שרת ה-8000).
  ✅ הצלחה: רשימת הפורטים המאזינים.

## חלק ה' — חיפוש וצינורות (🟠 מתקדם)

**2.18** — מצא את כל קובצי ה-SUID במערכת, וסנן שגיאות הרשאה.
```bash
find / -perm -4000 -type f 2>/dev/null
```
  💡 רמז: `2>/dev/null` "בולע" שגיאות הרשאה כדי שהפלט יהיה נקי. זה וקטור הסלמה (מודול 11)!
  ✅ הצלחה: קיבלת רשימת קבצים עם דגל SUID.

**2.19** — כמה משתמשים מוגדרים ב-`/etc/passwd`?
```bash
cat /etc/passwd | wc -l
```
  💡 רמז: כל שורה = משתמש; `wc -l` סופר שורות.
  ✅ הצלחה: יש לך מספר.

**2.20** — הצג רק את השורות ב-`/etc/passwd` שמכילות `bash` (משתמשים עם shell פעיל).
```bash
grep bash /etc/passwd
```
  👀 **חפש:** שורות שמסתיימות ב-`/bin/bash` — אלה חשבונות אמיתיים עם shell.
  ✅ הצלחה: קיבלת רק את השורות הרלוונטיות.

## 🔴 אתגר מסכם — "סקריפט הסיור הראשון"

בצע ידנית **רצף סיור** על מכונת Kali שלך ותעד את הפלט של כל שלב:

1. מי אני ובאילו הרשאות (`whoami`, `id`, `sudo -l`).
2. פרטי הרשת (IP, Gateway, DNS).
3. הפורטים הפתוחים המאזינים (`ss -tulpn`).
4. חיפוש קובצי SUID (`find / -perm -4000 -type f 2>/dev/null`).
5. תוכן `/etc/passwd` — מי המשתמשים עם shell.
6. **מסקנה:** 2–3 שורות — לו היית תוקף, איזה מסלול הסלמה נראה הכי מבטיח, ולמה.

  💡 רמז: כל הפקודות כבר תרגלת אותן למעלה. רק הרץ ברצף ותעד.
  ✅ הצלחה: מסמך עם פלט של 5 השלבים + מסקנה.

> 📤 זהו למעשה "Local Enumeration" — בדיוק מה שעושים בשלב שאחרי הפריצה (מודול 11). שמור את הפלט.
