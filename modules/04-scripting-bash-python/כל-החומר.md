# חלק א' — Bash Scripting

## 4.1 מהו סקריפט Bash?

**סקריפט Bash** הוא קובץ טקסט עם רצף פקודות Terminal, שרץ בזו אחר זו. כך הופכים סדרת פקודות ידניות לכלי אוטומטי.

```bash
#!/bin/bash
# השורה הראשונה — "Shebang" — אומרת למערכת להריץ עם bash
echo "Hello, Hacker!"
```

**הרצה:**
```bash
chmod +x script.sh   # הפיכה לניתן-הרצה (זוכרים ממודול 2?)
./script.sh          # הרצה
```

> 💡 ה-`#!/bin/bash` הוא **Shebang** — חובה בתחילת כל סקריפט. שורות שמתחילות ב-`#` (מלבד ה-Shebang) הן הערות.

### 🎬 הדגמה — נסה בעצמך: הסקריפט הראשון שלך
> נכתוב, נהפוך לניתן-הרצה, ונריץ — כל מחזור החיים של סקריפט, ב-30 שניות.

**צעד 1 — צור את הקובץ:**
```bash
nano hello.sh
```
הקלד בפנים (ואז `Ctrl+O`, Enter, `Ctrl+X`):
```bash
#!/bin/bash
echo "אני האקר, והסקריפט הראשון שלי רץ!"
echo "המשתמש שלי: $(whoami)"
```
**צעד 2 — נסה להריץ (וזה ייכשל):**
```bash
./hello.sh          # Permission denied — עוד אין הרשאת הרצה
```
**צעד 3 — תן הרשאת הרצה, ואז הרץ:**
```bash
chmod +x hello.sh   # זוכרים ממודול 2?
./hello.sh
```
👀 עכשיו זה עובד — והשורה `$(whoami)` הורצה בתוך הסקריפט.

🎯 **מה קרה כאן:** סקריפט הוא קובץ טקסט עם פקודות. בלי `chmod +x` המערכת לא תריץ אותו. ה-`$( )` מריץ פקודה ומחזיר את הפלט שלה — טריק שנשתמש בו הרבה.

**🧠 בדוק את עצמך:** קיבלת `Permission denied` על סקריפט חדש. מה חסר?
- א) שכחת את ה-Shebang
- ב) לא נתת הרשאת הרצה (`chmod +x`)
- ג) הקובץ ריק

> ✅ **תשובה: ב** — קובץ טקסט חדש אינו ניתן-הרצה כברירת מחדל. `chmod +x` מוסיף את הרשאת ה-execute.

## 4.2 משתנים וקלט משתמש

```bash
#!/bin/bash
name="Kali"                 # הצבה — ללא רווחים סביב ה-=
echo "Target is $name"      # שימוש — עם $

read -p "Enter an IP: " ip  # קלט מהמשתמש
echo "You entered $ip"
```

- **ללא רווחים** סביב ה-`=` (זו טעות נפוצה: `name = "x"` שגוי).
- `$name` — קורא את הערך. `${name}` — צורה בטוחה יותר בתוך מחרוזת.
- **ארגומנטים משורת הפקודה:** `$1`, `$2` = הארגומנט הראשון/שני; `$#` = מספרם.

```bash
#!/bin/bash
echo "First argument: $1"   # ./script.sh 10.0.0.5 → 10.0.0.5
```

## 4.5 פרויקט Bash — Ping Sweep

כלי אמיתי: סורק תת-רשת ומזהה אילו מכונות **חיות** (Host Discovery) — בדיוק מה שעושים בתחילת שלב הסריקה.

```bash
#!/bin/bash
# ping_sweep.sh — מוצא מכונות חיות בתת-רשת /24
# שימוש: ./ping_sweep.sh 192.168.1

if [ -z "$1" ]; then
    echo "Usage: $0 <network>   e.g. $0 192.168.1"
    exit 1
fi

network=$1
echo "[*] Scanning $network.0/24 ..."

for ip in $(seq 1 254); do
    # -c 1 = חבילה אחת, -W 1 = timeout שנייה
    ping -c 1 -W 1 "$network.$ip" > /dev/null 2>&1 && \
        echo "[+] $network.$ip is UP" &
done
wait
echo "[*] Sweep complete."
```

**איך זה עובד:**
1. בודק שהתקבל ארגומנט רשת (`$1`), אחרת מדפיס שימוש ויוצא.
2. לולאה על 1–254 (כל המארחים ב-`/24`).
3. `ping -c 1` לכל כתובת; אם הצליח (`&&`) — מדפיס שהמכונה חיה.
4. ה-`&` מריץ במקביל (מהיר יותר); `wait` ממתין לסיום כולם.

> ⚠️ הרץ רק על תת-הרשת של המעבדה שלך.

### 🎬 הדגמה — נסה בעצמך: הרץ את ה-Ping Sweep שלך
> נהפוך את הקוד לכלי אמיתי שמגלה מי חי ברשת — הצעד הראשון בכל סריקה.

**צעד 1 — שמור את הקוד** מ-§4.5 לקובץ `ping_sweep.sh` (`nano ping_sweep.sh`, הדבק, שמור).
**צעד 2 — הרשאת הרצה:**
```bash
chmod +x ping_sweep.sh
```
**צעד 3 — הרץ על הרשת שלך.** מצא קודם את הרשת שלך (`ip a` → למשל `192.168.56`), ואז:
```bash
./ping_sweep.sh 192.168.56       # שים את שלושת המספרים הראשונים של ה-IP שלך
```
👀 תוך שניות — רשימת המכונות ה**חיות** (`is UP`). אם אתה לבד, לפחות ה-Gateway והמארח יופיעו.
> 💡 אין מעבדה? נסה `./ping_sweep.sh 127.0.0` — לפחות `127.0.0.1` (אתה) יענה.

🎯 **מה קרה כאן:** הלולאה שלחה `ping` ל-254 כתובות במקביל (`&`) וסיננה רק את החיות. במקום לבדוק ידנית מכונה-מכונה — הסקריפט עשה זאת בשנייה. זה **Host Discovery**, השלב הראשון בסריקה (מודול 6).

**🧠 בדוק את עצמך:** מה תפקיד ה-`&` בסוף שורת ה-`ping` בלולאה?
- א) מריץ כל ping ברקע, כך שכולם רצים במקביל (מהיר)
- ב) מפנה את הפלט לקובץ
- ג) עוצר את הלולאה

> ✅ **תשובה: א** — ה-`&` שולח כל פקודה לרקע, כך שכל 254 ה-pings רצים במקביל; `wait` ממתין שכולם יסתיימו. בלי זה הסריקה הייתה איטית פי מאה.

## 4.10 פרויקט Python — Port Scanner

הכלי המרכזי של המודול — מיישם את **TCP** ואת **לחיצת היד** ממודול 3:

```python
#!/usr/bin/env python3
import socket
import sys

target = input("[*] Enter target IP: ")   # קלט מהמשתמש
print(f"[*] Scanning {target}")

try:
    for port in range(1, 1025):            # פורטים 1–1024
        s = socket.socket(socket.AF_INET, socket.SOCK_STREAM)  # TCP over IPv4
        s.settimeout(0.5)                  # אל תחכה יותר מחצי שנייה
        result = s.connect_ex((target, port))  # מחזיר 0 אם פתוח
        if result == 0:
            print(f"[+] Port {port} is OPEN")
        s.close()
except KeyboardInterrupt:
    print("\n[!] Stopped by user")
    sys.exit()
except socket.gaierror:
    print("[!] Hostname could not be resolved")
    sys.exit()
```

**שורה אחר שורה:**
1. `socket.socket(AF_INET, SOCK_STREAM)` — יוצר חיבור TCP מעל IPv4.
2. `settimeout(0.5)` — מונע היתקעות על פורט חסום.
3. `connect_ex((target, port))` — מנסה את לחיצת היד; מחזיר `0` אם הפורט **פתוח**.
4. הלולאה עוברת על 1–1024; `try/except` מטפל ב-Ctrl+C ובשגיאות DNS.

> ⚠️ הרץ **אך ורק** על `127.0.0.1` או מכונות המעבדה שלך.

## 4.11 מיני-פרויקט: פורץ סיסמאות (Brute Force) 🔓
> זה הרגע. תכתוב כלי שפורץ שירות מאובטח — בדיוק כמו `hydra` שנפגוש במודול 8.

**הרקע:** שרת קטן ([`pin_server.py`](pin_server.py)) מוגן ב-**PIN בן 4 ספרות**. החולשה: **אין הגבלת נסיונות**. יש 10,000 אפשרויות בלבד (0000–9999) — מחשב מנסה את כולן בשניות.

### 🎬 הדגמה — נסה בעצמך: פצח את ה-PIN
**צעד 1 — טרמינל 1: הפעל את המטרה:**
```bash
python3 pin_server.py
```
👀 השרת מאזין על פורט 9999. (למדריך בלבד הוא מדפיס את ה-PIN — התלמידים יתעלמו וינסו לפצח.)

**צעד 2 — טרמינל 2: שגר את התוקף** ([`brute_force.py`](brute_force.py)):
```bash
python3 brute_force.py
```
👀 הסקריפט רץ על 0000→9999, ותוך שניות מדפיס:
```text
[+] נמצא! ה-PIN הוא: 7111
[+] תשובת השרת: OK flag{brute_force_beats_weak_pins}
```
**צעד 3 — הבן את הקוד:** פתח את `brute_force.py`. הלב הוא הלולאה `for n in range(10000)` + `f"{n:04d}"` (הופך `42` ל-`"0042"`) ופונקציית `try_pin` ששולחת כל ניחוש בסוקט.

🎯 **מה קרה כאן:** בנית **מתקפת Brute Force** אמיתית — לולאה + סוקט + פונקציה, כל מה שלמדת במודול. השרת נפל כי PIN קצר + אין הגבלת נסיונות. **המסקנה ההגנתית:** סיסמאות ארוכות + נעילה אחרי X נסיונות.

**🏆 אתגר כיתתי:** מי מפצח מהר יותר? שנו את ה-PIN ל-6 ספרות ב-`pin_server.py` — כמה זמן ייקח עכשיו? (רמז: פי 100).

**🧠 בדוק את עצמך:** מה עשה את השרת **פגיע** ל-Brute Force?
- א) שהוא כתוב בפייתון
- ב) PIN קצר (4 ספרות) בלי הגבלת מספר נסיונות
- ג) שהוא רץ על פורט 9999

> ✅ **תשובה: ב** — מרחב קטן (10,000) + נסיונות בלתי מוגבלים = פריצה ודאית. הגנה: סיסמאות ארוכות ו-Rate Limiting / נעילת חשבון.

## חלק ב' — תרחיש מהחיים האמיתיים

### ⚙️ "כתוב כלי אוטומציה אמיתי"
בבדיקה יש לך רשימת יעדים ואתה רוצה לזהות מהר אילו מהם מריצים שרת web על פורט 80. **כתוב והרץ במעבדה** סקריפט Python שעושה זאת:

**דרישות:**
1. רשימת יעדים (List) — למשל `["127.0.0.1", "192.168.1.1"]`.
2. עבור כל יעד, בדוק אם פורט **80** פתוח (בעזרת `socket`).
3. הדפס `[+] <ip> has web server` רק ליעדים שבהם 80 פתוח.
4. טפל בשגיאות (timeout / כתובת לא תקינה).

**רמז:** שלב את `connect_ex`, לולאת `for`, ותנאי `if`.

### 💡 פתרון מנחה
```python
#!/usr/bin/env python3
import socket

targets = ["127.0.0.1", "192.168.1.1"]   # התאם למעבדה שלך
port = 80

for ip in targets:
    try:
        s = socket.socket(socket.AF_INET, socket.SOCK_STREAM)
        s.settimeout(0.5)
        if s.connect_ex((ip, port)) == 0:
            print(f"[+] {ip} has web server (port 80 open)")
        s.close()
    except socket.error:
        print(f"[!] {ip} — error")
```
**בדיקה:** הפעל שרת מקומי `python3 -m http.server 80` (כ-root) ותראה את `127.0.0.1` מזוהה.

> 🎯 זהו למעשה סורק ממוקד-שירות — אותו רעיון של nmap, אך משלך. הבנת הקוד הזה = הבנת איך כלי סריקה עובדים מבפנים.

תראה `[+] Port 80 is OPEN`. **שים לב:** הסורק מ-README סורק פורטים 1–1024 בלבד, לכן פתחנו את השירות על **80** (בטווח) ולא על 8000 (מחוץ לטווח). כדי לסרוק פורטים גבוהים יותר — הרחב את ה-`range()` בקוד (כמו באתגר המסכם).

**4.12** —
- `connect_ex` מחזיר **0** כשהפורט פתוח (החיבור הצליח).
- `settimeout(0.5)` מגביל את ההמתנה לחיבור — מונע היתקעות על פורט מסונן ומאיץ את הסריקה.
- `try/except KeyboardInterrupt` מאפשר לעצור בנקישת Ctrl+C בצורה נקייה במקום קריסה מכוערת.

## 🔴 אתגר מסכם — פתרון מלא

```python
#!/usr/bin/env python3
import socket, sys, time

services = {21:"FTP",22:"SSH",80:"HTTP",443:"HTTPS",3389:"RDP",8000:"HTTP-alt"}

target = input("[*] Enter target: ")
start_port = int(input("[*] Start port: "))
end_port   = int(input("[*] End port: "))

print(f"[*] Scanning {target} ports {start_port}-{end_port}")
open_count = 0
start_time = time.time()

try:
    for port in range(start_port, end_port + 1):
        s = socket.socket(socket.AF_INET, socket.SOCK_STREAM)
        s.settimeout(0.5)
        if s.connect_ex((target, port)) == 0:
            name = services.get(port, "")
            print(f"[+] Port {port} is OPEN ({name})" if name else f"[+] Port {port} is OPEN")
            open_count += 1
        s.close()
except KeyboardInterrupt:
    print("\n[!] Stopped by user"); sys.exit()

elapsed = round(time.time() - start_time, 1)
print(f"[*] Scan complete. Found {open_count} open ports in {elapsed}s")
```

**בונוס Bash — שרשור Ping Sweep + Scanner:**
```bash
#!/bin/bash
# מוצא מכונות חיות, ואז מריץ את סורק הפייתון על כל אחת
network=$1
for ip in $(seq 1 254); do
    if ping -c 1 -W 1 "$network.$ip" > /dev/null 2>&1; then
        echo "[+] $network.$ip is UP — scanning..."
        echo "$network.$ip" | python3 scanner.py
    fi
done
```
