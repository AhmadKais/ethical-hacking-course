# 🎯 משימות השלמה — מודול 04: סקריפטינג ב-Bash וב-Python

> משימות אלה **משלימות** את [המשימות המעשיות](missions.md): הן מתמקדות ב**ניתוח**, ב**הגנה (Blue Team)**, ב**מחקר** ובאתגר מסכם — להעמקת ההבנה ולראייה הגנתית, לצד הלמידה ההתקפית.

> ⚠️ **הרשאה ו-Scope:** כל פעילות מעשית מתבצעת **רק** על מכונת תרגול חוקית, סביבת לימוד מוכרת (כמו TryHackMe), או מערכת שבבעלותכם ובהרשאתכם המפורשת. איסוף פסיבי על מידע פומבי מותר; פעולות אקטיביות על יעד שאינו שלכם — **אסורות**.

> **מקרא רמות:** 🟢 בסיסי · 🟡 בינוני · 🔴 אתגר

## משימה 1 — תיקון סקריפט 🟢
🎯 **מטרה:** לקרוא קוד ולאתר באג.
נתון סקריפט Bash שאמור להדפיס 1 עד 5 אך אינו עובד. זהו שתי בעיות אפשריות (תחביר/לוגיקה) ותקנו:
```bash
for i in {1..5}
  echo $i
```
💡 **רמז:** ללולאת `for` ב-Bash חסרים `do` ו-`done`.
✅ **הצלחה:** הסקריפט המתוקן מדפיס 1–5.

## משימה 2 — Ping Sweep 🟢
🎯 **מטרה:** להבין אוטומציה של משימה חוזרת.
1. כתבו (בפסאודו-קוד או ב-Bash) לולאה שעוברת על כתובות `192.168.1.1` עד `192.168.1.10` ובודקת מי מגיב ל-`ping`.
2. הסבירו: למה עדיף לולאה על הקלדה ידנית של עשר פקודות?
⚠️ הריצו רק על **רשת המעבדה שלכם**.
✅ **הצלחה:** לולאה תקינה, והסבר על ערך האוטומציה.

## משימה 3 — Port Scanner בפייתון 🟡
🎯 **מטרה:** להבין איך כלי סריקה עובד מבפנים.
1. בפייתון, השתמשו בספריית `socket` כדי לכתוב פונקציה שמנסה להתחבר לפורט בודד ומחזירה "פתוח/סגור".
2. הסבירו איזו שורה בקוד מבצעת בפועל את ניסיון החיבור.
⚠️ בדקו רק מול `127.0.0.1` או מכונת מעבדה שבבעלותכם.
✅ **הצלחה:** הקוד מזהה פורט פתוח מול לוקאלהוסט, ואתם מסבירים את `socket.connect`.

## משימה 4 — Bash או Python? 🟡
🎯 **מטרה:** לבחור כלי נכון למשימה.
לכל משימה, בחרו Bash או Python ונמקו: (א) שינוי שם ל-100 קבצים, (ב) ניתוח קובץ JSON מורכב, (ג) הרצת רצף פקודות מערכת, (ד) בניית כלי עם מבני נתונים.
✅ **הצלחה:** א/ג→Bash, ב/ד→Python, עם נימוק (פשטות מול עושר).

## אתגר — הכלי שלכם 🔴
🎯 **מטרה:** לבנות כלי שימושי קטן.
כתבו סקריפט (Bash או Python) שמקבל קובץ טקסט של כתובות IP ומדפיס רק את התקינות (פורמט `x.x.x.x`). תעדו את הקוד ודוגמת הרצה.
✅ **הצלחה:** הכלי מסנן כתובות תקינות; הקוד מתועד.
