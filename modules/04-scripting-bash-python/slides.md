## מודול 4 — Scripting: Bash & Python

- יסודות: משתנים ומבני נתונים
- תנאים, לולאות, פונקציות
- מודולים ו-socket
- פרויקט: סורק פורטים

## למה Python?

- השפה הנפוצה בכלי אבטחה ואוטומציה
- רוב ה-Exploits והסקריפטים כתובים בה
- לא צריך להיות מתכנת
- מספיק לקרוא, לשנות ולכתוב סקריפטים

## משתנים וטיפוסים

- **String** — טקסט: `"nmap"`
- **Integer** — מספר שלם: `443`
- **Float** — עשרוני: `2.5`
- **Boolean** — `True` / `False`

## מבני נתונים

- **List** `[ ]` — מסודר, משתנה
- **Dictionary** `{key: value}` — מיפוי
- **Tuple** `( )` — קבוע
- דוגמה: `services = {80: "HTTP"}`

## תנאים ולולאות

- `if / elif / else` — קבלת החלטות
- `for port in range(1, 101)` — טווח
- `while` — כל עוד תנאי מתקיים
- הבסיס לאוטומציה

## פונקציות ומודולים

- **פונקציה** — אריזת קוד לשימוש חוזר
- `def scan_port(ip, port):`
- **socket** — תקשורת רשת
- **sys** — ארגומנטים ומערכת

## פרויקט: סורק פורטים

- יוצר socket מסוג TCP לכל פורט
- `connect_ex()` מחזיר 0 = פורט פתוח
- לולאה על טווח 1–1024
- `try/except` לטיפול בשגיאות ו-Ctrl+C

## הקוד המרכזי

```python
s = socket.socket(socket.AF_INET,
                  socket.SOCK_STREAM)
s.settimeout(0.5)
if s.connect_ex((target, port)) == 0:
    print(f"[+] Port {port} OPEN")
s.close()
```
