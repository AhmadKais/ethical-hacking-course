# 🎯 משימות מעשיות — מודול 1: מבוא, מעבדה ו-Kali Linux

> **לפני שתתחיל:** כל המשימות מתבצעות במעבדה הפרטית שלך בלבד. ראה [חומר הלימוד](README.md) לרקע התיאורטי.

מקרא רמות: 🟢 בסיסי · 🟡 בינוני · 🔴 אתגר

## משימה 1 — הקמת המעבדה 🟢

**מטרה:** להתקין ולהפעיל את Kali Linux בסביבה וירטואלית.

**צעדים:**
1. הורד והתקן **VMware Workstation Player** (או VirtualBox).
2. הורד את דמות ה-VM המוכנה של Kali מ-[kali.org](https://www.kali.org/get-kali/#kali-virtual-machines).
3. חלץ את הקובץ וטען אותו ב-VMware (`File → Open`).
4. הגדר: RAM = 2GB לפחות, Processors = 2.
5. הפעל והתחבר עם `kali` / `kali`.

**✅ קריטריון הצלחה:** אתה מחובר לשולחן העבודה של Kali ורואה את שורת המשימות.

**❓ שאלת בדיקה:** מדוע עדיף להשתמש במכונה וירטואלית ולא להתקין Kali ישירות על המחשב?

## משימה 2 — בידוד רשת המעבדה 🟢

**מטרה:** לוודא שהמעבדה מבודדת ולא תתקוף בטעות את הרשת הביתית.

**צעדים:**
1. ב-VMware פתח `VM → Settings → Network Adapter`.
2. שנה את המצב ל-**Host-Only** או **NAT**.
3. הפעל את Kali ופתח Terminal.
4. הרץ `ip a` וזהה את כתובת ה-IP שקיבלה המכונה.

**✅ קריטריון הצלחה:** ה-IP של Kali נמצא בטווח פרטי (למשל `192.168.x.x` או `10.x.x.x`).

> ⚠️ **חשוב:** לעולם אל תריץ כלי תקיפה כשהמתאם במצב Bridged אלא אם אתה יודע בדיוק מה אתה עושה.

## משימה 3 — מיפוי חמשת השלבים 🟡

**מטרה:** להטמיע את מתודולוגיית התקיפה.

**צעדים:**
1. צייר טבלה עם חמשת השלבים (Recon → Scanning → Gaining Access → Maintaining Access → Covering Tracks).
2. לכל שלב רשום: (א) מה מטרתו במשפט, (ב) כלי אחד אופייני.

**✅ קריטריון הצלחה:** הטבלה מלאה ואתה יכול לדקלם את חמשת השלבים בעל פה.

**❓ שאלת בדיקה:** לאיזה שלב שייכת סריקת `nmap`? לאיזה שלב שייך חיפוש עובד ב-LinkedIn?

---

## משימה 4 — היכרות עם ארגז הכלים 🟡

**מטרה:** לנווט בתפריט הכלים של Kali ולזהות כלים לפי קטגוריה.

**צעדים:**
1. פתח את תפריט `Applications` ב-Kali.
2. אתר **כלי אחד** בכל אחת מהקטגוריות: Information Gathering, Exploitation Tools, Password Attacks.
3. עבור כל כלי, הרץ בטרמינל `<tool> -h` או `man <tool>` וקרא את שורת התיאור.

**✅ קריטריון הצלחה:** רשמת 3 כלים + מה כל אחד עושה במשפט.

---

## משימה 5 — פקודות Linux ראשונות 🟡

**מטרה:** להתמצא בשורת הפקודה — הבסיס לכל שאר הקורס.

הרץ ותעד את הפלט של כל פקודה:
```bash
whoami          # מי המשתמש הנוכחי
pwd             # באיזו תיקייה אני נמצא
ls -la          # רשימת קבצים כולל מוסתרים
ip a            # כתובות הרשת
uname -a        # פרטי מערכת ההפעלה והליבה (Kernel)
sudo apt update # עדכון רשימת החבילות
```

**✅ קריטריון הצלחה:** אתה מבין מה כל פקודה מחזירה.

## 🔴 אתגר מסכם — "הכרטיס האישי של המעבדה"

הכן מסמך קצר (או צילומי מסך) המתעד את המעבדה שהקמת:

1. צילום מסך של Kali פועל עם Terminal פתוח.
2. פלט הפקודה `ip a` — עם ה-IP הפרטי מודגש.
3. פלט `uname -a` — גרסת ה-Kernel.
4. טבלת חמשת השלבים (ממשימה 3).
5. משפט אחד: "המעבדה שלי מבודדת כי ______".

**זהו ה"בסיס" שלך לכל שאר הקורס. שמור אותו.**
