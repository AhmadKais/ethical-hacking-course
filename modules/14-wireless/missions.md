# 🎯 תרגילים — מודול 14: תקיפות אלחוטיות

> ⚠️ **רק על רשת אלחוטית שבבעלותך או שקיבלת עליה אישור בכתב.** האזנה/תקיפה של רשת זרה = עבירה פלילית. חלק מהתרגילים דורשים **מתאם Wi-Fi עם Monitor Mode**; מי שאין לו — יבצע את תרגילי הפיצוח (על קובצי `.cap`) והתיאוריה. פתרונות ב-[**`solutions.md`**](solutions.md).

> ### 🚦 לפני שמתחילים — קרא אותי!
> - **מה צריך:** **Kali** + **מתאם Wi-Fi USB שתומך ב-Monitor Mode ו-Injection** (הכרטיס המובנה לרוב לא מספיק, וגם לא עובד ב-VM ללא USB passthrough). **אין חומרה?** תרגל את התיאוריה ואת תרגילי ה**פיצוח** על קובץ `.cap` להורדה.
> - **איך עובדים:** קרא קודם את ה-[`README.md`](README.md). למשימות עם פקודה — **הפקודה מופיעה** + מה לחפש; לרעיוניות **💡 רמז**.
> - **נתקעת?** אם `airmon-ng` לא נכנס ל-monitor mode — הכרטיס/דרייבר לא תומך. נסה, ואז הצץ ב-[`solutions.md`](solutions.md).
> - **טיפ:** התרגיל הכי חשוב — בדוק את הרשת שלך בבית. רוב האנשים מגלים שהסיסמה שלהם ב-rockyou.

## חלק א' — תיאוריה וסביבה (🟢)

**14.1** — הסבר את ההבדל בין SSID, BSSID ו-Client. מהו Beacon Frame?
  💡 רמז: README §14.1.
  ✅ הצלחה: SSID=שם, BSSID=MAC של ה-AP, Client=מכשיר מחובר, Beacon=שידור נוכחות.

**14.2** — סדר את WEP, WPA, WPA2, WPA3 מהחלש לחזק. מדוע WEP "שבור"?
  💡 רמז: README §14.2.
  ✅ הצלחה: הסדר נכון + הסבר חולשת ה-IV של WEP.

**14.3** 🟢 — הפעל **Monitor Mode** ואמת.
```bash
sudo airmon-ng check kill
sudo airmon-ng start wlan0
iwconfig wlan0mon
```
  👀 **חפש:** `Mode:Monitor` בפלט של `iwconfig`.
  ✅ הצלחה: המתאם במצב Monitor (`wlan0mon`).

## חלק ב' — סריקה ולכידה (🟡🟠)

**14.4** 🟡 — סרוק את הרשתות בסביבתך וזהה את **הרשת שלך**.
```bash
sudo airodump-ng wlan0mon
```
  👀 **חפש:** בטבלה — BSSID, CH (ערוץ), ENC (WPA2), ESSID של הרשת שלך. רשום אותם.
  ✅ הצלחה: יש לך BSSID + ערוץ + הצפנה של הרשת שלך.

**14.5** 🟠 — התמקד ברשת שלך ולכוד **Handshake**.
```bash
sudo airodump-ng --bssid <BSSID> -c <ערוץ> -w capture wlan0mon
```
  👀 **חפש:** למעלה מופיע `WPA handshake: <BSSID>` — סימן שלכדת.
  ✅ הצלחה: לכדת את ה-Handshake לקובץ.

**14.6** 🟠 — בצע **Deauth** על מכשיר שלך כדי לזרז את הלכידה.
```bash
sudo aireplay-ng --deauth 5 -a <BSSID> -c <client-mac> wlan0mon
```
  💡 רמז: README §14.5. מעט חבילות (5) מספיקות — המטרה חיבור מחדש אחד, לא DoS.
  ✅ הצלחה: המכשיר התנתק והתחבר מחדש, וה-Handshake נלכד.

## חלק ג' — פיצוח ומתקדם (🟠)

**14.7** 🟠 — פצח את ה-Handshake.
```bash
sudo aircrack-ng capture-01.cap -w /usr/share/wordlists/rockyou.txt
# או hashcat:
hcxpcapngtool -o hash.hc22000 capture-01.cap
hashcat -m 22000 hash.hc22000 /usr/share/wordlists/rockyou.txt
```
  👀 **חפש:** `KEY FOUND! [ הסיסמה ]` — אם הסיסמה במילון.
  ✅ הצלחה: פיצחת (או קבעת שהסיסמה חזקה מדי — וזה טוב!).

**14.8** 🟠 — זהה רשת עם **WPS** פעיל. למה WPS וקטור תקיפה?
```bash
sudo wash -i wlan0mon
```
  💡 רמז: README §14.7. ה-PIN בן 8 ספרות → brute-force עם reaver.
  ✅ הצלחה: זיהית אם WPS פעיל והסברת את הסיכון.

**14.9** 🟠 — הסבר כיצד **Evil Twin** מצליח גם מול WPA2 חזק.
  💡 רמז: README §14.7. הוא לא תוקף הצפנה — מרמה את המשתמש.
  ✅ הצלחה: הסברת שהוא עוקף הצפנה דרך הטעיה (הנדסה חברתית).

## 🔴 אתגר מסכם — "בדיקת אבטחת ה-Wi-Fi הביתי"

על **הרשת האלחוטית שלך בבית** (בעלות מלאה):

1. סרוק וזהה את פרטי הרשת (BSSID, ערוץ, הצפנה).
2. לכוד Handshake (עם Deauth של מכשיר שלך).
3. נסה לפצח עם rockyou. **האם הסיסמה שלך שרדה?**
4. בדוק אם WPS פעיל.
5. **תעד דוח:** ממצאים (WPS? חוזק סיסמה?), והמלצות (WPA3, סיסמה חזקה, כיבוי WPS).

  💡 רמז: כל השלבים בתרגילים 14.3–14.8. מבנה דוח ב-[`solutions.md`](solutions.md).
  ✅ הצלחה: דוח על הרשת שלך + המלצות שיפור.

> 📤 בדיקה זו על הרשת שלך בטוחה, חוקית וחושפת — אם הסיסמה שלך נמצאה, שדרג אותה מיד.
