## 15.1 החוליה האנושית

טכנולוגיה אפשר להקשיח; **אנשים** קשה יותר. הנדסה חברתית מנצלת **רגש והרגלים** — לא באגים בקוד:
- **סמכות** — "המנכ"ל ביקש".
- **דחיפות** — "החשבון שלך יינעל תוך שעה!".
- **פחד** — "זוהתה פעילות חשודה".
- **סקרנות / תאוות בצע** — "זכית!", "ראה מי צפה בפרופיל שלך".

> 🎯 מהנדס חברתי טוב לא "פורץ" — הוא **משכנע** את הקורבן לפתוח בעצמו את הדלת. הכלי המרכזי הוא פסיכולוגיה, לא קוד.

---

## 15.2 עקרונות ההשפעה (צ'לדיני)

ששת עקרונות ההשפעה של רוברט צ'לדיני, שתוקפים מנצלים:

| עיקרון | ניצול בהתקפה |
|--------|--------------|
| **Reciprocity** (הדדיות) | "נתתי לך משהו, עכשיו תעזור לי" |
| **Commitment** (עקביות) | הסכמה קטנה → הסכמה גדולה |
| **Social Proof** (הוכחה חברתית) | "כל העובדים כבר עדכנו" |
| **Authority** (סמכות) | התחזות למנהל/IT/רשות |
| **Liking** (חיבה) | בניית קרבה ואמון לפני הבקשה |
| **Scarcity** (מחסור) | "הצעה מוגבלת", "רק היום" |

> 💡 רוב מיילי הפישינג המוצלחים משלבים **סמכות + דחיפות**: "מחלקת IT — אפס את הסיסמה תוך 24 שעות אחרת תיחסם".

---

## 15.3 סוגי מתקפות הנדסה חברתית

| מתקפה | ערוץ | תיאור |
|-------|------|-------|
| **Phishing** | אימייל | מייל המוני מזויף עם לינק/קובץ זדוני |
| **Spear Phishing** | אימייל | פישינג **ממוקד** לאדם ספציפי (מותאם אישית) |
| **Whaling** | אימייל | ספיר-פישינג ל**בכיר** (מנכ"ל, סמנכ"ל) |
| **Vishing** | טלפון | הנדסה חברתית קולית ("מדבר נציג הבנק") |
| **Smishing** | SMS | פישינג בהודעות טקסט |
| **Pretexting** | כל ערוץ | בניית **תרחיש כיסוי** אמין ("אני הטכנאי החדש") |
| **Baiting** | פיזי | פיתיון — USB "אבוד" בחניון עם תווית מפתה |
| **Tailgating** | פיזי | כניסה למתחם בעקבות עובד מורשה |

> 🔍 **Spear Phishing** הוא היעיל ביותר בבדיקות אמיתיות — מייל מותאם אישית (שם, תפקיד, פרויקט אמיתי) מקבל שיעורי לחיצה גבוהים בהרבה ממייל גנרי.

## 15.4 OSINT — איסוף מודיעין על המטרה

לפני מתקפה ממוקדת — אוספים מידע **גלוי** (Open Source Intelligence):

```bash
# איסוף כתובות מייל ושמות מהדומיין:
theHarvester -d company.com -b all

# מיפוי נוכחות דיגיטלית:
# - LinkedIn: שמות עובדים, תפקידים, טכנולוגיות
# - אתר החברה: מבנה מיילים (firstname.lastname@)
# - GitHub: קוד, מפתחות שדלפו
# - Google Dorking:  site:company.com filetype:pdf
```
כלים נוספים: **Maltego** (מיפוי קשרים גרפי), **hunter.io** (מיילים), **haveibeenpwned** (דליפות).

> 🎯 OSINT הוא הבסיס לספיר-פישינג משכנע: ככל שתדע יותר על הקורבן (תפקיד, פרויקטים, קולגות) — כך המייל ייראה אמין יותר. זה מתחבר ישירות למודול 5 (Recon).

## 15.5 אנטומיה של מייל פישינג

מייל פישינג משכנע כולל:
1. **כתובת שולח מזויפת/דומה** — `it-suport@company.com` (שים לב לשגיאת הכתיב), או Display Name מזויף.
2. **נושא דחוף** — "פעולה נדרשת: אימות חשבון".
3. **מיתוג אמין** — לוגו, צבעים, חתימה של הארגון.
4. **קריאה לפעולה** — לינק ("לחץ כאן") או קובץ מצורף.
5. **דף נחיתה מזויף** — עמוד התחברות שנראה אמיתי, שולח את הפרטים לתוקף.

**סימני זיהוי (להדרכת עובדים):**
```text
⚠️ שולח לא מוכר / דומיין שגוי במעט
⚠️ דחיפות ואיומים
⚠️ שגיאות כתיב ותרגום מכונה
⚠️ לינק שה-URL האמיתי שלו שונה מהטקסט (רחף מעליו!)
⚠️ בקשה לפרטי התחברות / פרטים אישיים
```

## 15.6 בניית קמפיין פישינג (GoPhish)

**GoPhish** הוא framework חינמי לניהול קמפיין פישינג **מבוקר** (מדידת מודעות עובדים):

```bash
# הרצה:
./gophish
# ממשק ניהול ב- https://localhost:3333
```
שלבי בניית קמפיין:
1. **Sending Profile** — שרת ה-SMTP לשליחה.
2. **Landing Page** — שבט (clone) של דף התחברות אמיתי; לוכד credentials ומפנה לאתר האמיתי.
3. **Email Template** — תבנית המייל (עם משתנים: `{{.FirstName}}`, `{{.URL}}`).
4. **Users & Groups** — רשימת היעדים (מ-OSINT).
5. **Campaign** — הרצה + מעקב: מי פתח, מי לחץ, מי הזין פרטים.

> 📊 GoPhish מפיק **דוח מדדים**: אחוז פתיחה, אחוז לחיצה, אחוז מסירת פרטים — בדיוק מה שהלקוח צריך למדוד את מודעות העובדים ולתכנן הדרכות.

---

## 15.7 כלים נוספים (SET, evilginx)

- **SET (Social-Engineer Toolkit)** — ארגז כלים קלאסי: Credential Harvester (שבט אתר), Spear-Phishing, יצירת Payloads.
```bash
sudo setoolkit
# 1) Social-Engineering Attacks → 2) Website Attack → 3) Credential Harvester
```
- **evilginx2** — פרוקסי מתקדם שעוקף **MFA** ע"י גניבת ה-**session token** (לא רק הסיסמה) — מדגים מדוע פישינג עדיין מסוכן גם עם 2FA.
- **King Phisher** — חלופה ל-GoPhish.

> ⚠️ evilginx וגניבת session מדגימים ללקוח שגם MFA אינו "כדור כסף" — אך זהו כלי רב-עוצמה שיש להשתמש בו **אך ורק** בהרשאה מפורשת ובתיעוד מלא.

## 15.8 אתיקה, חוק והגנה

**כאן האתיקה קריטית מתמיד** — מדובר באנשים אמיתיים:
- **הרשאה בכתב** מההנהלה, עם **Scope** ברור (מי מותר, מי לא — אף פעם לא HR/רפואה/אישי).
- **אל תשפיל / תלחיץ** מעבר לנדרש; המטרה חינוך, לא ענישה.
- **דיווח מרוכז** — לא "שיימינג" של עובדים שנפלו; מדווחים אחוזים, לא שמות.
- **מחיקת נתונים** שנאספו (credentials) בסיום.

**הגנה (להמלצות בדוח):**
- **הדרכות מודעות** תקופתיות + סימולציות פישינג.
- **MFA** בכל מקום (מקטין נזק מגניבת סיסמה).
- **סינון מייל** (SPF/DKIM/DMARC, אנטי-פישינג).
- **תרבות "שאל אם לא בטוח"** — קל לדווח על מייל חשוד.

> ⚖️ בדיקת הנדסה חברתית מודדת **מוכנות ארגונית** ומחנכת — לא "תופסת" עובדים. הצג את התוצאות כהזדמנות לשיפור, לעולם לא כהאשמה אישית.

## סיכום המודול

- **האדם** הוא החוליה החלשה; ~90% מהפריצות מתחילות בפישינג.
- תוקפים מנצלים **עקרונות השפעה** (סמכות, דחיפות, פחד) — לא באגים.
- סוגים: Phishing, **Spear Phishing** (הכי יעיל), Vishing, Pretexting, Baiting.
- **OSINT** (theHarvester, LinkedIn, Maltego) מזין ספיר-פישינג משכנע.
- **GoPhish / SET** בונים קמפיין מבוקר עם מדדים; **evilginx** עוקף MFA.
- **אתיקה קריטית:** הרשאה, Scope, דיווח מרוכז ללא שיימינג; הגנה = הדרכות + MFA + סינון.

## 🔴 אתגר מסכם — "תרגיל מודעות פישינג (מבוקר)"

תכנן קמפיין הדרכת מודעות מלא **על ארגון פיקטיבי** (או מעבדה בהסכמה):

1. **OSINT** — אסוף "מטרות" (רשימה פיקטיבית) ומבנה מיילים.
2. **תסריט (Pretext)** — בחר תרחיש אמין (IT / HR / משלוח).
3. **בנה** ב-GoPhish: Template + Landing Page + Group.
4. **הרץ** על כתובות שלך/הסכמה, ואסוף מדדים.
5. **תעד דוח:** אחוזי פתיחה/לחיצה/מסירה, **בלי שמות**, + המלצות. כתוב את **קטע האתיקה** — איך תציג תוצאות מבלי לבייש עובדים.

  💡 רמז: מבנה דוח מלא + דגשי אתיקה ב-[`solutions.md`](solutions.md).
  ✅ הצלחה: דוח מודעות עם מדדים (ללא שמות) והמלצות + קטע אתיקה.

> 📤 דוח מודעות פישינג הוא תוצר מרכזי בבדיקות PNPT. הדגש את הצד המחנך.

## חלק א' — שאלות תרגול

**Q1.** למה "האדם הוא החוליה החלשה ביותר"? מה אחוז הפריצות שמתחילות בפישינג?

**Q2.** אילו שני עקרונות השפעה משולבים ברוב מיילי הפישינג המוצלחים?

**Q3.** מה ההבדל בין Spear Phishing ל-Whaling?

**Q4.** מהו Pretexting? תן דוגמה.

**Q5.** איך OSINT הופך ספיר-פישינג ליעיל יותר?

**Q6.** מה עושה GoPhish, ואילו מדדים הוא מספק?

**Q7.** איך evilginx עוקף MFA?

**Q8.** מהו הכלל האתי המרכזי בהצגת תוצאות סימולציית פישינג?

### ✅ תשובות
1. אפשר להקשיח טכנולוגיה אך קשה להקשיח אנשים; ~**90%** מהפריצות מתחילות בפישינג.
2. **סמכות + דחיפות** (למשל "IT — אפס סיסמה תוך 24 שעות").
3. Spear Phishing = ממוקד לאדם ספציפי; Whaling = ספיר-פישינג ל**בכיר** (מנכ"ל/סמנכ"ל).
4. בניית **תרחיש כיסוי** אמין לפני הבקשה; למשל "אני הטכנאי החדש, צריך את הסיסמה לבדיקה".
5. מידע (תפקיד, פרויקטים, קולגות) הופך את המייל למותאם ואמין → שיעורי לחיצה גבוהים בהרבה.
6. Framework לקמפיין פישינג מבוקר; מדדים: אחוז פתיחה, לחיצה, ומסירת פרטים.
7. reverse proxy שגונב את ה-**session cookie** אחרי אימות מוצלח → כניסה ללא MFA נוסף.
8. **דיווח מרוכז ללא שמות** — אחוזים בלבד; המטרה חינוך ולא שיימינג/ענישה.

---

## חלק ב' — תרחיש מהחיים האמיתי

### 🎣 "מהמייל אל ה-Domain"
בבדיקת PNPT (בהרשאה מלאה), התחלת ללא גישה פנימית כלל. המטרה: דריסת רגל ברשת דרך הגורם האנושי.

```text
1. OSINT   → theHarvester + LinkedIn: 40 עובדים, מבנה מייל
             first.last@corp.com, טכנולוגיה: Office 365.
2. Pretext → "מחלקת IT: מעבר ל-Office 365 חדש, התחבר לאימות".
3. GoPhish → Landing Page שבט של דף התחברות O365.
4. שליחה   → 40 עובדים; 14 לחצו, 6 הזינו סיסמה.
5. גישה    → אחת הסיסמאות עבדה ב-VPN → רגל בדלת →
             משם Kerberoasting ו-AD (מודול 13).
```

**המשימה:**
1. מדוע שלב ה-OSINT היה **קריטי** להצלחת הקמפיין?
2. אילו **שתי** הגנות טכניות היו מפחיתות משמעותית את הנזק בשלב 5?
3. כיצד תציג את התוצאה (6 עובדים מסרו סיסמה) בדוח **מבלי לפגוע** בהם?

### 💡 פתרון מנחה
1. OSINT חשף את **מבנה המיילים, שמות העובדים והטכנולוגיה (O365)** — בלעדיו לא היינו יכולים לבנות דף נחיתה משכנע או לדעת למי לשלוח. הוא הבסיס לכל ספיר-פישינג.
2. (א) **MFA** — גם עם סיסמה נכונה, ה-VPN היה חוסם ללא הגורם השני; (ב) **סינון מייל (DMARC/אנטי-פישינג)** — חלק מהמיילים היו נחסמים לפני שהגיעו.
3. מדווחים **אחוז** (15% מסרו פרטים) ולא שמות; ממסגרים כ"הזדמנות להדרכה" ומציעים תוכנית מודעות — לעולם לא רשימת "נכשלים".

> 🎯 שרשרת "פישינג → סיסמה → VPN → AD" היא איך פריצות אמיתיות באמת קורות. הגורם האנושי הוא לרוב הכניסה הקלה ביותר — ולכן הדרכה + MFA הם ההגנה החשובה ביותר.

## חלק א' — עקרונות

**15.1**
- **Reciprocity** — "צירפתי לך קופון, אשר את הפרטים".
- **Commitment** — סקר קצר → בהמשך בקשת סיסמה.
- **Social Proof** — "כל המחלקה כבר עדכנה את הפרטים".
- **Authority** — "מדבר מנהל ה-IT / הבנק".
- **Liking** — בניית קרבה בצ'אט לפני הבקשה.
- **Scarcity** — "הקישור בתוקף ל-24 שעות בלבד".

**15.2** — **Phishing** = המוני וגנרי; **Spear Phishing** = ממוקד ומותאם אישית; **Whaling** = ספיר-פישינג לבכיר. **Spear Phishing הכי יעיל** — התאמה אישית (שם, תפקיד, פרויקט) מעלה דרמטית את שיעור הלחיצה.

**15.3** — סימנים: דומיין שולח שגוי, דחיפות/איום, שגיאות כתיב, לינק שה-URL שלו שונה מהטקסט, בקשת פרטי התחברות.

## חלק ב' — OSINT ותכנון

**15.4**
```bash
theHarvester -d company.com -b all
# + LinkedIn (עובדים/תפקידים), GitHub, Google Dorking
```
לרוב מפתיע כמה מידע ציבורי קיים: מיילים, מבנה ארגוני, טכנולוגיות.

**15.5** — מזהים דפוס מ-OSINT (מייל אחד שדלף) → `firstname.lastname@` → מרכיבים כתובות לכל העובדים שמצאת ב-LinkedIn.

**15.6** — דוגמה: *"מאת: IT Support. עקב שדרוג אבטחה, אפס את סיסמתך תוך 24 שעות בקישור המצורף אחרת חשבונך יושבת."* — משלב **Authority** (IT) + **Scarcity/Urgency** (24 שעות) + **Fear** (השבתה).

## חלק ג' — קמפיין מבוקר

**15.7**
```bash
./gophish            # ממשק ב- https://localhost:3333
# Landing Pages → Import Site (שבט) → Capture Credentials
# Email Templates → HTML עם {{.URL}}
```

**15.8** — צור Group עם **המייל שלך בלבד**, הרץ Campaign, ובדוק בלשונית Results: Email Opened / Clicked Link / Submitted Data נרשמים.

**15.9** — **evilginx** יושב כ-**reverse proxy** בין הקורבן לאתר האמיתי; הקורבן מתחבר (כולל MFA) דרכו, ו-evilginx **גונב את ה-session cookie** אחרי האימות. עם ה-cookie התוקף נכנס בלי לעבור MFA שוב → מוכיח ש-2FA לא עוצר פישינג מתקדם (אך כן מקשה).
