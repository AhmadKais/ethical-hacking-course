## חלק ב' — OSINT ותכנון (🟡)

**15.4** 🟡 — בצע **OSINT** על עצמך (או חברה בהסכמה).
```bash
theHarvester -d <domain> -b all
```
  👀 **חפש:** מיילים, שמות ותת-דומיינים שהכלי מצא. + חפש ב-LinkedIn.
  ✅ הצלחה: הפתעת מכמות המידע הציבורי שקיים.

**15.5** 🟡 — נסח **מבנה מיילים** של ארגון (`first.last@`) והסבר איך OSINT עוזר לנחש כתובות.
  💡 רמז: README §15.4.
  ✅ הצלחה: הסברת איך מדפוס אחד מרכיבים כתובות לכל העובדים.

**15.6** 🟡 — כתוב **טקסט** של מייל ספיר-פישינג ("איפוס סיסמת IT"). אילו עקרונות השפעה שילבת?
  💡 רמז: README §15.2, §15.5. שלב סמכות + דחיפות.
  ✅ הצלחה: מייל משכנע + זיהוי העקרונות שהשתמשת בהם.

## חלק ג' — קמפיין מבוקר (🟠)

**15.7** 🟠 — התקן והרץ **GoPhish**, צור Template ו-Landing Page **במעבדה שלך בלבד**.
```bash
./gophish        # ממשק ב- https://localhost:3333
```
  💡 רמז: README §15.6. Landing Pages → Import Site (שבט) → Capture Credentials.
  ✅ הצלחה: יש לך Template ו-Landing Page מוכנים.

**15.8** 🟠 — הרץ **קמפיין ניסיוני על עצמך** ובדוק שהמדדים נרשמים.
  💡 רמז: README §15.6. צור Group עם המייל שלך בלבד, הרץ Campaign, בדוק Results.
  ✅ הצלחה: ראית מדדי פתיחה/לחיצה נרשמים בדוח.

**15.9** 🟠 — הסבר כיצד **evilginx** עוקף MFA.
  💡 רמז: README §15.7. reverse proxy שגונב את ה-session cookie.
  ✅ הצלחה: הסברת מדוע 2FA לא עוצר פישינג מתקדם.

## 🔴 אתגר מסכם — "תרגיל מודעות פישינג (מבוקר)"

תכנן קמפיין הדרכת מודעות מלא **על ארגון פיקטיבי** (או מעבדה בהסכמה):

1. **OSINT** — אסוף "מטרות" (רשימה פיקטיבית) ומבנה מיילים.
2. **תסריט (Pretext)** — בחר תרחיש אמין (IT / HR / משלוח).
3. **בנה** ב-GoPhish: Template + Landing Page + Group.
4. **הרץ** על כתובות שלך/הסכמה, ואסוף מדדים.
5. **תעד דוח:** אחוזי פתיחה/לחיצה/מסירה, **בלי שמות**, + המלצות. כתוב את **קטע האתיקה** — איך תציג תוצאות מבלי לבייש עובדים.

  💡 רמז: מבנה דוח מלא + דגשי אתיקה ב-[`solutions.md`](solutions.md).
  ✅ הצלחה: דוח מודעות עם מדדים (ללא שמות) והמלצות + קטע אתיקה.

> 📤 דוח מודעות פישינג הוא תוצר מרכזי בבדיקות PNPT. הדגש את הצד המחנך.
