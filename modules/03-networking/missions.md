## משימה 1 — זיהוי כתובות המכונה שלך 🟢

**מטרה:** לקרוא את פרטי הרשת של המחשב.

**צעדים (ב-Kali):**
```bash
ip a               # כתובת IP + MAC
ip route            # שער ברירת המחדל (Gateway)
cat /etc/resolv.conf  # שרת ה-DNS
```

**✅ קריטריון הצלחה:** זיהית את ה-IP, ה-MAC, ה-Gateway ושרת ה-DNS של המכונה.

**❓ שאלה:** האם ה-IP שלך פרטי או ציבורי? לפי איזה טווח קבעת?

## משימה 2 — מסע של חבילה עם ping ו-traceroute 🟢

**מטרה:** להבין ניתוב ו-ICMP.

```bash
ping -c 4 8.8.8.8            # בדיקת קישוריות (ICMP)
ping -c 4 google.com        # מי מתרגם את השם לכתובת?
traceroute google.com       # דרך אילו צמתים עוברת החבילה
```

**✅ קריטריון הצלחה:** ראית את כתובת ה-IP שאליה תורגם `google.com`, ורשימת הצמתים בדרך.

**❓ שאלה:** איזה פרוטוקול תרגם את `google.com` לכתובת IP?

## משימה 4 — לתפוס לחיצת יד עם Wireshark 🟡

**מטרה:** לראות בעיניים את ה-3-Way Handshake של TCP.

**צעדים:**
1. פתח **Wireshark** ב-Kali והתחל לכידה על מתאם הרשת.
2. במסנן (Filter) הקלד: `tcp.flags.syn == 1`
3. בטרמינל אחר הרץ: `curl http://example.com`
4. חזור ל-Wireshark ואתר את רצף החבילות: **SYN → SYN,ACK → ACK**.

**✅ קריטריון הצלחה:** זיהית את שלוש החבילות של פתיחת החיבור.

> 💡 שים לב: החבילה הראשונה נשלחת ממך (SYN), השנייה מהשרת (SYN,ACK), והשלישית שוב ממך (ACK).

## משימה 5 — חישוב Subnet 🟡

**מטרה:** להבין את גבולות תת-הרשת.

ענה על השאלות עבור הרשת `192.168.10.0/24`:
1. כמה כתובות יש בתת-הרשת?
2. מהי מסכת הרשת (Subnet Mask) בכתיב עשרוני?
3. אם נריץ `nmap 192.168.10.0/24` — כמה כתובות ייסרקו?

בדוק את עצמך עם:
```bash
ipcalc 192.168.10.0/24
```

**✅ קריטריון הצלחה:** תשובותיך תואמות את פלט `ipcalc`.

## 🔴 אתגר מסכם — "מפת הרשת שלי"

1. שרטט (בכלי כלשהו או ביד) את מפת המעבדה שלך: מכונת Kali, ה-Gateway, ושרת ה-DNS — עם כתובות ה-IP.
