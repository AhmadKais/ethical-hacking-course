# 🎯 תרגילים — מודול 3: יסודות רשתות

> ב-Terminal של Kali. פתרונות מלאים ב-[**`solutions.md`**](solutions.md).

> ### 🚦 לפני שמתחילים — קרא אותי!
> - **מה צריך:** מכונת **Kali** דולקת. לחלק ד' נשתמש ב-**Wireshark** (מותקן ב-Kali).
> - **🌐 חשוב — אינטרנט:** תרגילים **3.7** ו-**3.14** (ping/traceroute לאינטרנט) דורשים ש-Kali יהיה במצב רשת **NAT** (יש אינטרנט). אם הגדרת **Host-Only** (כמו שהומלץ למעבדת תקיפה) — **אין אינטרנט**, וה-ping ייכשל. פשוט החלף זמנית ל-NAT: `Settings → Network → Adapter 1 → NAT` (ולאחר מכן חזרה ל-Host-Only לתרגול תקיפה).
> - **איך עובדים:** קרא קודם את ה-[`README.md`](README.md). לשאלות ידע יש **💡 רמז** לסעיף המתאים; למשימות המעשיות (🟢) **הפקודה המדויקת + מה לחפש**.
> - **נתקעת?** קרא שוב את הסעיף ב-README (יש שם טבלאות עזר), ואז הצץ ב-[`solutions.md`](solutions.md). אם פקודה מחזירה `command not found` — התקן אותה עם `sudo apt install <שם> -y`.
> - **טיפ:** רשת היא הבסיס לכל סריקה — אם משהו לא ברור, אל תתקדם עד שהבנת.

## חלק א' — ידע ומודלים (🟢 קל)

**3.1** — מנה את 7 שכבות מודל OSI מלמעלה למטה, ולכל שכבה תן פרוטוקול/דוגמה אחת.
  💡 רמז: README §3.2 (טבלת OSI). טריק לזכירה: *All People Seem To Need Data Processing*.
  ✅ הצלחה: 7 שכבות בסדר (Application→Physical) + דוגמה לכל אחת.

**3.2** — לאיזו שכבת OSI שייך כל אחד? HTTP · IP · Ethernet/MAC · TCP · ARP.
  💡 רמז: README §3.2.
  ✅ הצלחה: HTTP=7, TCP=4, IP=3, Ethernet/MAC=2, ARP=2.

**3.3** — הסבר את ההבדל בין TCP ל-UDP, ותן שירות אחד לכל אחד.
  💡 רמז: README §3.4.
  ✅ הצלחה: TCP=אמין/מבוסס-חיבור (HTTP), UDP=מהיר/ללא חיבור (DNS).

**3.4** — כתוב את שלושת שלבי ה-3-Way Handshake לפי הסדר.
  💡 רמז: README §3.4.
  ✅ הצלחה: SYN → SYN-ACK → ACK.

## חלק ב' — הכתובות שלי (🟢🟡)

**3.5** 🟢 — מצא את כתובת ה-IP, ה-MAC וה-Gateway של Kali.
```bash
ip a          # IP (inet) ו-MAC (link/ether) תחת eth0
ip route      # Gateway (default via ...)
```
  👀 **חפש:** `inet` = ה-IP; `link/ether` = ה-MAC; `default via X` = ה-Gateway.
  ✅ הצלחה: רשמת את שלושת הערכים.

**3.6** 🟢 — האם ה-IP שלך פרטי או ציבורי? לפי איזה טווח קבעת?
  💡 רמז: README §3.5 (טווחים פרטיים: 10.x, 172.16–31.x, 192.168.x).
  ✅ הצלחה: קבעת נכון + ציינת את הטווח.

**3.7** 🟡 — הרץ `ping` ל-IP ואז לשם, וזהה מי תרגם את השם. *(דורש אינטרנט — מצב NAT; ראה ההערה למעלה.)*
```bash
ping -c 4 8.8.8.8
ping -c 4 google.com
```
  👀 **חפש:** לפני התשובה מ-google.com מופיע ה-IP שלו — **DNS** תרגם את השם ל-IP.
  ✅ הצלחה: הבנת ש-DNS ביצע את התרגום משם לכתובת IP. *(אם מקבל `Destination Host Unreachable` — אתה כנראה ב-Host-Only; עבור ל-NAT.)*

**3.8** 🟡 — הצג את טבלת ה-ARP של המכונה.
```bash
ip neigh      # או: arp -a
```
  👀 **חפש:** זוגות של IP ↔ MAC של מכונות ברשת המקומית.
  ✅ הצלחה: ראית את מיפוי ה-IP↔MAC.

## חלק ג' — פורטים ותת-רשתות (🟡🟠)

**3.9** 🟡 — מלא מהזיכרון: הפרוטוקול/שירות עבור 21, 22, 80, 443, 445, 3389.
  💡 רמז: README §3.7 (טבלת הפורטים).
  ✅ הצלחה: 21=FTP, 22=SSH, 80=HTTP, 443=HTTPS, 445=SMB, 3389=RDP.

**3.10** 🟠 — עבור `10.10.50.0/24`: כמה כתובות? מסכה? כמה מארחים שמישים?
```bash
sudo apt install ipcalc -y     # אם עדיין לא מותקן (לרוב לא מגיע מראש)
ipcalc 10.10.50.0/24
```
  👀 **חפש:** `Netmask` (255.255.255.0), `Hosts/Net` (254).
  ✅ הצלחה: 256 כתובות, מסכה /24, 254 מארחים שמישים.

**3.11** 🟠 — אם תריץ `nmap 172.16.0.0/16`, כמה כתובות תיאורטית ייסרקו? האם זה רעיון טוב?
  💡 רמז: /16 = 2 בתים למארחים = 256×256.
  ✅ הצלחה: ~65,536 כתובות; רעיון גרוע לסריקה מלאה (איטי ורועש) — עדיף לצמצם טווח.

## חלק ד' — לראות את הרשת בעיניים (🟠 מתקדם)

**3.12** — לכוד את ה-Handshake ב-Wireshark.
```bash
# פתח Wireshark → התחל לכידה על eth0, ואז בטרמינל:
curl http://example.com
```
  👀 **חפש:** מסנן `tcp` — אתר את רצף **SYN → SYN-ACK → ACK**. צרף צילום מסך.
  ✅ הצלחה: זיהית את שלוש חבילות פתיחת החיבור.

**3.13** — ב-Wireshark, סנן `dns`, גלוש לאתר, וזהה Query ו-Response.
  💡 רמז: השאילתה (Query) שואלת "מה ה-IP?" והתשובה (Response) מחזירה אותו.
  ✅ הצלחה: ראית זוג Query/Response של תרגום שם.

**3.14** — הרץ `traceroute` וספור צמתים.
```bash
traceroute google.com
```
  👀 **חפש:** כל שורה = צומת (Hop) בדרך ליעד; ספור כמה יש.
  ✅ הצלחה: יש לך מספר Hops והבנת שכל שורה = ראוטר בדרך.

## 🔴 אתגר מסכם — "מפת הרשת שלי"

1. **מפה:** שרטט את מפת המעבדה — Kali, ה-Gateway, שרת ה-DNS — עם כתובות IP ו-MAC.
2. **Handshake חי:** צרף צילום מסך מ-Wireshark של שלוש חבילות פתיחת החיבור.
3. **ניתוח פורטים:** הסבר במשפט לכל פורט — מדוע 445 (SMB) ו-3389 (RDP) הם יעדי תקיפה מרכזיים.
4. **תת-רשת:** בהינתן שאתה ב-`192.168.1.50/24`, מה טווח הכתובות שתסרוק במודול 6, ובאיזו פקודת nmap?
5. **מסקנה:** 2–3 שורות — מהרשת שמיפית, מה הצעד הבא ההגיוני.

  💡 רמז: כל הנתונים כבר בתרגילים 3.5–3.14. טווח לסריקה: `192.168.1.0/24` עם `nmap -sn`.
  ✅ הצלחה: מסמך עם מפה, צילום Handshake, וניתוח + מסקנה.

> 📤 שמור — זו התשתית שעליה נבצע סריקה אקטיבית במודול 6.
