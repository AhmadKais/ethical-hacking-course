# 🧠 תרגול — מודול 3: יסודות רשתות

> חלק א' — **שאלות תרגול** (עם תשובות). חלק ב' — **תרחיש מהחיים האמיתיים**.

## חלק א' — שאלות תרגול

**Q1.** מנה את 7 שכבות OSI, ולכל אחת פרוטוקול לדוגמה.

**Q2.** מהם שלושת שלבי ה-3-Way Handshake?

**Q3.** בסריקת nmap: איזו תשובה מעידה שפורט פתוח? סגור? מסונן?

**Q4.** לאיזה שירות שייך כל פורט: 21, 22, 80, 443, 445, 3389?

**Q5.** מה ההבדל בין TCP ל-UDP? תן שירות לכל אחד.

**Q6.** כמה כתובות ב-`/24`? כמה שמישות? ומה הפקודה לחישוב?

**Q7.** מה עושה ARP, ומהי מתקפת ARP Poisoning?

**Q8.** הכתובת `172.20.5.10` — פרטית או ציבורית? לפי איזה טווח?

### ✅ תשובות
1. Application(HTTP), Presentation(TLS), Session(RPC), Transport(TCP), Network(IP), Data Link(Ethernet/ARP), Physical(כבל).
2. SYN → SYN-ACK → ACK.
3. פתוח=SYN-ACK; סגור=RST; מסונן=אין תשובה.
4. 21=FTP, 22=SSH, 80=HTTP, 443=HTTPS, 445=SMB, 3389=RDP.
5. TCP אמין ומבוסס-חיבור (HTTP/מייל); UDP מהיר וללא חיבור (DNS/סטרימינג).
6. 256 כתובות, 254 שמישות; `ipcalc 192.168.1.0/24`.
7. ARP מתרגם IP↔MAC ברשת מקומית; Poisoning = תוקף עונה בשקר ומיירט תעבורה (MITM).
8. פרטית — טווח 172.16.0.0/12.

## חלק ב' — תרחיש מהחיים האמיתיים

### 🔍 "ניתוח לחיצת יד ב-Wireshark"
אתה בבדיקה פנימית ורוצה להבין את התעבורה ברשת. **בצע במעבדה:**

```bash
# טרמינל 1 — פתח Wireshark (או tcpdump):
sudo wireshark &
# בסינון הקלד: tcp.flags.syn==1
# טרמינל 2 — צור תעבורה:
curl http://example.com
```

**המשימה:**
1. אתר ב-Wireshark את שלוש חבילות פתיחת החיבור. איזו יצאה ממך, ואיזו מהשרת?
2. שנה את הסינון ל-`dns`. גלוש לאתר וזהה את שאילתת התרגום. איזה פרוטוקול תעבורה (TCP/UDP) ואיזה פורט?
3. אם היית תוקף ברשת זו — אילו שתי מתקפות שכבה-2/3 היו רלוונטיות למה שראית?

### 💡 פתרון מנחה
1. **SYN** יצא ממך (הלקוח), **SYN-ACK** מהשרת, ואז **ACK** ממך — פתיחת החיבור.
2. DNS פועל מעל **UDP פורט 53**; תראה `Standard query` ו-`query response`.
3. **ARP Poisoning** (MITM על שכבה 2) לאיסוף תעבורה, ו-**DNS Spoofing** (זיוף תשובת DNS) להפניית הקורבן לשרת זדוני.

> 🎯 לראות את המנגנונים "בחיים" (Handshake, DNS) הופך את התיאוריה למוחשית — וזה בסיס להבנת סריקות (מודול 6) ומתקפות רשת.
