## חלק א' — ידע ומודלים

**3.1 — 7 שכבות OSI (7→1):**
7. Application (HTTP) · 6. Presentation (TLS) · 5. Session (RPC) · 4. Transport (TCP/UDP) · 3. Network (IP) · 2. Data Link (Ethernet/ARP) · 1. Physical (כבל/Wi-Fi).

**3.2 — שיוך לשכבות:**
- HTTP → שכבה 7 (Application)
- IP → שכבה 3 (Network)
- Ethernet/MAC → שכבה 2 (Data Link)
- TCP → שכבה 4 (Transport)
- ARP → שכבה 2 (Data Link)

**3.3 — TCP מול UDP:**
TCP אמין ומבוסס-חיבור (לחיצת יד, מוודא הגעה) — למשל HTTP/מייל. UDP מהיר וללא חיבור ("יורה ושוכח") — למשל DNS/סטרימינג.

**3.4 — 3-Way Handshake:**
1. Client → SYN → Server
2. Client ← SYN-ACK ← Server
3. Client → ACK → Server (החיבור פתוח)

## חלק ב' — הכתובות שלי

**3.5**
```bash
ip a        # שורת inet = IP, שורת link/ether = MAC
ip route    # default via X.X.X.X = ה-Gateway
```

**3.6** — אם קיבלת `192.168.x.x` → פרטי (טווח 192.168.0.0/16). `10.x.x.x` → פרטי (10.0.0.0/8). כתובת אחרת שאינה בטווחים הפרטיים → ציבורית.

**3.7**
```bash
ping -c 4 8.8.8.8       # IP ישיר — אין צורך ב-DNS
ping -c 4 google.com    # קודם DNS מתרגם את השם ל-IP, ואז ping
```
ההבדל: בשם צריך תחילה תרגום **DNS**; רואים בפלט את ה-IP שהתקבל.

**3.8**
```bash
ip neigh     # (או arp -a)
```
הטבלה מכילה מיפוי בין כתובות IP מקומיות לכתובות ה-MAC המתאימות — מכשירים שהמכונה תקשרה איתם לאחרונה.

## חלק ג' — פורטים ותת-רשתות

**3.9** — 21/TCP FTP · 22/TCP SSH · 80/TCP HTTP · 443/TCP HTTPS · 445/TCP SMB · 3389/TCP RDP.

**3.10** — `10.10.50.0/24`:
- סך כתובות: **256**
- מסכה: **255.255.255.0**
- מארחים שמישים: **254** (פחות כתובת הרשת וה-Broadcast)
```bash
sudo apt install ipcalc -y     # אם צריך
ipcalc 10.10.50.0/24
```

**3.11** — `/16` = **65,536** כתובות. לסרוק את כולן זה **לא** רעיון טוב בבת אחת — זה איטי מאוד ורועש (מתגלה בקלות). עדיף קודם **Host Discovery** (`nmap -sn 172.16.0.0/16`) כדי למצוא מכונות חיות, ואז לסרוק רק אותן.

## חלק ד' — לראות את הרשת בעיניים

**3.12** — ב-Wireshark, מסנן `tcp.flags.syn==1` יעזור לאתר. תראה:
1. חבילה עם דגל SYN (ממך לשרת)
2. חבילה עם SYN+ACK (מהשרת)
3. חבילה עם ACK (ממך)

**3.13** — מסנן `dns` יראה שתי חבילות: **Standard query** (השאלה "מה ה-IP של X?") ו-**Standard query response** (התשובה עם ה-IP). זהו שכבה 7 מעל UDP פורט 53.

**3.14**
```bash
traceroute google.com
```
כל שורה = צומת (Router) אחד בדרך ליעד, עם זמן התגובה שלו. מספר ה-Hops הוא מספר השורות. הצמתים הראשונים הם ברשת שלך/הספק.

## 🔴 אתגר מסכם — קווים מנחים

1. **מפה:** דיאגרמה עם Kali (למשל 192.168.1.50), Gateway (192.168.1.1), DNS.
2. **Handshake:** צילום Wireshark של SYN/SYN-ACK/ACK.
3. **פורטים:** 445 (SMB) — שיתוף קבצים Windows, וקטור לתנועה רוחבית ולחולשות כמו EternalBlue. 3389 (RDP) — גישה גרפית מרוחקת, יעד ל-Brute Force ולגישה ראשונית.
4. **תת-רשת:** ב-`/24` תסרוק את `192.168.1.0/24` (256 כתובות) עם `nmap -sn 192.168.1.0/24` ואז סריקת שירותים על החיות.
5. **מסקנה לדוגמה:** "מיפיתי רשת /24 עם Gateway ב-.1. הצעד הבא: Host Discovery כדי למצוא מכונות חיות, ואז סריקת פורטים ושירותים (מודול 6) על היעדים שיימצאו."
