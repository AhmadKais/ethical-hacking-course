# 🛡️ האקינג אתי מהיסוד

**Ethical Hacking from Zero** — קורס מלא בעברית לבדיקות חדירה (Penetration Testing), ממתחילים ועד רמה מקצועית.

מבוסס על מתודולוגיית *Practical Ethical Hacking* של TCM Security, בתוספת מודולים משלימים (Web / OWASP, אלחוט, הסלמת הרשאות, כתיבת דוח) לכיסוי מלא של המקצוע.

---

## 🎬 מעבדה מעשית — כל מודול כולל "יעד לפריצה"

**הקורס מעשי מהרגע הראשון.** כמעט כל מודול מגיע עם **יעד פגיע קטן שאתם מפעילים ותוקפים בעצמכם** (שרת, אתר, או תוכנית פגיעה) — ואחרי כל נושא יש **🎬 הדגמה — נסה בעצמך** (צעד-אחר-צעד) ו-**🧠 בדוק את עצמך** (שאלת רב-ברירה). הכול רץ **מקומית על Kali**, ללא צורך במכונות נוספות.

> ### 🚀 איך מריצים את ההדגמות (קרא פעם אחת!)
> **1. הורד את הקורס למכונת ה-Kali שלך:**
> ```bash
> git clone https://github.com/AhmadKais/ethical-hacking-course.git
> cd ethical-hacking-course
> ```
> (אין git? `sudo apt install git -y`. או הורד ZIP מ-GitHub ופתח אותו.)
>
> **2. לכל הדגמה — היכנס לתיקיית המודול הרלוונטית לפני ההרצה.** הפקודות כמו `python3 demo_server.py` מניחות שאתה **בתוך** תיקיית המודול:
> ```bash
> cd modules/07-exploitation      # לדוגמה, למודול 7
> python3 vuln_webapp.py          # עכשיו זה יעבוד
> ```
>
> **3. שים לב — מעטפת ברירת המחדל ב-Kali היא `zsh`.** רוב הפקודות עובדות זהה, אך פקודות מסוימות (למשל Reverse Shell עם `/dev/tcp`) חייבות לרוץ תחת `bash`. במקרים כאלה ההדגמה תציין זאת במפורש (`bash -c '...'`).
>
> **4. כלים:** כל הכלים בהם נשתמש (`nmap`, `john`, `hydra`, `hashcat`, `gcc`, `aircrack-ng`, `gobuster`...) **מותקנים מראש ב-Kali**. אם משהו חסר: `sudo apt install <שם-הכלי>`.
>
> **5. הכל בטוח:** כל היעדים מאזינים על `127.0.0.1` בלבד (המכונה שלך), ומיועדים לתרגול חוקי בלבד. ⚠️ תקיפת מערכת ללא רשות היא עבירה פלילית.

## 🚀 איך להשתמש בקורס

> 📘 **הכי פשוט — קובץ אחד לגלילה:** בכל מודול יש קובץ [`כל-החומר.md`](modules/01-intro-lab-methodology/כל-החומר.md) שמרכז את **כל** תוכן המודול ברצף אחד — חומר → תרגילים → תרגול → פתרונות. פותחים אותו וגוללים למטה שלב-אחר-שלב. הקבצים הנפרדים קיימים לצדו למי שמעדיף.

1. **קרא את המודול** — כל מודול הוא תיקייה עם `README.md` (חומר צעד-אחר-צעד), או `כל-החומר.md` לגלילה רצופה.
2. **בצע את המשימות** — קובץ `missions.md` בכל מודול, עם תרגילים מדורגים ואתגר מסכם.
3. **חזור עם המצגת** — קובץ `slides.md` לסיכום מהיר.
4. **תרגל על מכונה חוקית** — [TryHackMe](https://tryhackme.com), [HackTheBox](https://www.hackthebox.com), [VulnHub](https://www.vulnhub.com).

### מבנה כל מודול
```
modules/NN-topic/
├── כל-החומר.md    # ⭐ הכול בקובץ אחד לגלילה: חומר→תרגילים→תרגול→פתרונות
├── README.md      # חומר הלימוד (צעד-אחר-צעד, עם דוגמאות)   → material.pdf
├── missions.md    # תרגילים מדורגים + אתגר מסכם
├── solutions.md   # פתרונות מלאים צעד-אחר-צעד             → exercises.pdf (missions+solutions)
├── practice.md    # שאלות תרגול (עם תשובות) + תרחיש אמיתי  → practice.pdf
├── slides.md      # מצגת (Markdown, נפתחת ישירות ב-GitHub)
├── slides.pdf     # 🖥️ המצגת כ-PDF — נפתחת ב-GitHub עמוד-אחר-עמוד (להצגה)
└── slides.pptx    # 📊 המצגת ל-PowerPoint (לעריכה והצגה)

# כל קובצי ה-PDF וה-PPTX נמצאים בתוך תיקיית המודול עצמה — הכול במקום אחד.
```

## 🧰 דרישות מקדימות

- **חומרה:** 16GB RAM מומלץ (8GB מינימום), ~100GB דיסק פנוי, וירטואליזציה מופעלת ב-BIOS.
- **תוכנה:** [VirtualBox](https://www.virtualbox.org) (חינמי, מומלץ) — או VMware Workstation Pro (חינמי לשימוש אישי מ-2024). ראה [מדריך הקמת המעבדה המאויר](resources/lab-setup-illustrated.md).
